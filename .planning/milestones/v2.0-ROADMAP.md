## Key Decisions

- BusinessNav uses `createBusinessBrowserClient()` exclusively — consumer client never referenced (session isolation)
- RSC layout (`app/business/layout.tsx`) stays RSC while rendering BusinessNav (client) — RSC/client boundary inside BusinessNav
- `cookies()` called synchronously — Next.js 14.2.35 canonical pattern (no await)
- Business map uses same two-step zoom+CalloutCard flow as main map — consistent UX
- `/business/profiili` RSC guard uses `maybeSingle()` not `single()` — null on 0 rows, no error
- `contact_phone` is nullable TEXT with no constraints — business user may leave it empty
- BIZPRO-02 scoped to phone only — email/website are per-venue fields managed via WizardInner
