## Milestone Summary

**Key Decisions:**

- Outfit fonttivaihto CSS-muuttujatabstraktion kautta — nolla downstream-muutosta (D-22)
- SportPin inline HTML (ei erillistä komponenttia klustereille) — minimoi blast radiuksen
- CalloutCard iteroi alkuperäistä suunnitelmaa: pystysuunta + kirjain kerrallaan-animaatio käyttäjäpalautteen perusteella
- AktiiviLogo: rekursiivinen async runLoop() (ei setInterval) jotta asynkroninen sequencing on siisti
- Gradientti-väri SportPin/CalloutCard: #38bdf8→#0284c7 (sky blue gradient, sporttinen)
- FilterCarouselPill paikallinen komponentti Etusivu.tsx:ssä — ei erillinen tiedosto

**Issues Resolved:**

- Z-index bugi: CalloutCard peittyi muiden pinnien alle (korjattu zIndex 1→5)
- Carousel pill: outside-click handler lisätty jälkikäteen UX-korjauksen myötä
- Case-insensitive sport filter comparison (CR-01 code review fix)

**Issues Deferred:**

- MAP-15 osittainen: Laji-ikonit värillisinä vain callout-kortissa ja karttapinneissä, ei DiagonaalKortissa
- Logo-API: yritysten logot callout-kortteihin — siirretty kunnes website_domain-kenttä Supabasessa

**Technical Debt Incurred:**

- lib/sportPins.ts on tyhjä export {} -tiedosto (kommentti dokumentoi alkuperän)
- SPORT_ICONS duplikoitu CalloutCardissa Etusivu.tsx:ssä ja SportPin.tsx:ssä — voidaan refaktoroida lib/lajit.ts:ään
