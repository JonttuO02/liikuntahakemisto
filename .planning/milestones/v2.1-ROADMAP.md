## Key Decisions

- No Playwright — `fetch` only; Framer/SPA fallback is manual entry (cost/complexity tradeoff)
- FK references `business_accounts(user_id)` not `businesses` — correct table from Phase 31 schema
- One Claude API call per analysis (vision + text in same message) — cost efficiency
- `waitUntil` fire-and-forget: POST returns immediately; background pipeline survives Vercel function lifecycle
- Vercel Hobby 10s timeout for waitUntil — accepted limitation; Phase 46 polls `status=analyzing` until max 30 tries
- `raw_analysis` JSONB stores full `BrandingAnalysisResult` — Phase 46 reads `prices` and `opening_hours` without extra columns
- `business_branding` UNIQUE on `business_account_id` — one row per company; UPSERT on conflict
- DNS rebinding SSRF limitation accepted for v2.1 — hostname checked before DNS resolution; post-DNS IP validation deferred
- `page.tsx` converted to `'use client'` for phase state; RSC auth guard in `layout.tsx` runs first in Next.js pipeline
