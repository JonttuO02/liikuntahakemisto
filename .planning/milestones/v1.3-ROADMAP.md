# Milestone v1.3: AKTIIVI — Redesign & Polish

**Status:** ✅ SHIPPED 2026-05-30
**Phases:** 16–18
**Total Plans:** 8

## Overview

Rebranded the app from "Liikuntahakemisto" to "AKTIIVI" across all metadata and UI surfaces. Redesigned the map experience: unified sport pins with SVG icons, same-address venue clustering, and in-place card expansion via Framer Motion `layoutId`. Unified toolbar UX with a single search+filter button and a separate list-toggle.

## Milestone Summary

**Key Decisions:**
- Brand name is AKTIIVI — no "Liikuntahakemisto" in any user-visible metadata
- Pin color is always #ef4444 — sport identity communicated by icon shape, not color
- Cluster grouping key uses ±0.0001° rounding (~11m); popup uses reference equality for toggle
- Record<string,T[]> used for coord grouping (TS 5.9.3 Map<K,V> generic regression workaround)
- CalloutCard clip-path: path() with spike — no erillisiä elementtejä, spike computed via ResizeObserver
- layoutId-elementti ei saa omistaa translateX(-50%) — centering wrapper erillinen motion.div

**Issues Resolved:**
- TS 5.9.3 regression: `new Map<K,V>()` causes TS7009/TS2558 — fixed with Record<string,T[]>
- Callout card shifted right after sheet close — caused by translateX(-50%) on layoutId element; fixed by separating centering wrapper from layoutId motion.div

**Issues Deferred:**
- Google OAuth callback URL — vaatii manuaalisen Google Cloud Console + Supabase dashboard -konfiguroinnin
- /suosikit-sivu (Suosikkipaikat kirjautuneelle) — deferred v1.3

**Technical Debt Incurred:**
- 18-03 SUMMARY describes original in-place card (280px glass div above pin) — code evolved to PaikkaSheet + CalloutCard pattern post-plan; SUMMARY is slightly stale but functionally accurate
