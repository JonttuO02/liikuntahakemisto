## Overview

Täysi yritysportaali: yritys rekisteröityy, ottaa paikan haltuunsa tai luo uuden, käy läpi 6-vaiheisen onboarding-velhon (kuvat, logo, hinnasto, aukioloajat, yhteystiedot, esikatselu), odottaa admin-hyväksyntää, ja saa käyttöönsä hallintapaneelin (/business) kaikki tiedot kattavalla muokkausnäkymällä ja esikatselulla. Kaikki paikan data ylikirjoittaa Google Places -datan; `business_managed`-flag suojaa sync-skriptiltä.

## Milestone Summary

**Key Decisions:**

- Business auth: same Supabase Auth as regular users; role differentiated via business_accounts table (no separate project)
- Business media: Supabase Storage bucket `business-media`; RLS per yritys via business_paikka_links
- Business data priority: yrityksen data ylikirjoittaa Google Places -datan; business_managed-flag suojaa sync-skriptiltä
- Admin approval: required for initial registration; edits after approval are instant (no re-approval)
- Claim visibility: claim-paikka pysyy näkyvänä; uusi paikka hidden (published=false) until approved
- URLs: /business for panel, /business/onboarding for wizard, /admin for admin
- No payments in v1.7; no separate Supabase project

**Issues Resolved:**
- Migration history sort bug (20260528_reviews.sql underscore vs digit): renamed + remote migration version updated
- Supabase Storage RLS: SECURITY DEFINER function pattern required because storage schema is forbidden on hosted Supabase
- OnboardingWizardInner multi-venue contamination: paikka_id-scoped draft queries after Phase 36 revealed cross-venue state
- update-paikka API blocked pending/rejected venues (approved-only gate was wrong): fixed at milestone close

**Issues Deferred:**
- Missing VERIFICATION.md for Phase 33 (smoke-tested only) and Phase 36 (UAT only)
- claim-paikka route missing `business_managed=true` UPDATE (sync window between claim and onboarding submit)
- Wizard orchestrator fragmentation: OnboardingWizardInner + EditWizardInner share step components but duplicate all routing/guard logic — v1.8 cleanup: merge into single WizardInner with mode prop
- onboarding_completed column written but never read (dead data)
- `/admin` server-side middleware missing (client-side-only guard)
- Phase 33 no VERIFICATION.md

**Technical Debt Incurred:**
