## Requirements (9/9 complete)

### Navigation

- [x] **BIZNAV-01**: Business user sees a dedicated BusinessNav bar on all `/business/*` pages with links to Dashboard, Kartta, Profiili, and Kirjaudu ulos — *Phase 41*
- [x] **BIZNAV-02**: Consumer NavBar is not rendered on any `/business/*` page — *Phase 41*

### Authentication

- [x] **BIZUX-02**: User is automatically redirected to `/business` dashboard after successful login at `/business/kirjaudu` — *Phase 41*

### Dashboard

- [x] **BIZUX-03**: `/business` dashboard shows an approval status card (pending / approved / rejected + reapply CTA), a venue list with status badges, and quick-action links to Kartta and venue edit — *Phase 42*

### Map

- [x] **BIZUX-04**: `/business/map` shows a full-screen map of all published venues; a top-bar pill toggle switches between "Kaikki paikat" and "Omat paikat"; tapping a pin zooms in, shows CalloutCard, and opens PaikkaSheet — *Phase 42*

### Business Profile

- [x] **BIZPRO-01**: `/business/profiili` displays the business account's company name, email, and account type (read-only) — *Phase 43*
- [x] **BIZPRO-02**: `/business/profiili` allows the user to edit contact phone number and save it to `business_accounts` — *Phase 43* *(scoped down from phone+email+website to phone only; email/website are per-venue fields)*
- [x] **BIZPRO-03**: `/business/profiili` provides a FI/EN language toggle that persists in the `NEXT_LOCALE` cookie — *Phase 43*
- [x] **BIZPRO-04**: `/business/profiili` has a sign-out button that clears the `sb-biz-*` session and redirects to `/business/kirjaudu` — *Phase 43*
