## v1 Requirements — Final Status

### Security & Foundation

- [x] **SEC-01**: Käyttäjä ei voi triggeröidä Google Places API -hakuja ilman admin-autentikaatiota (`/api/hae-paikat` vaatii Authorization-headerin)
- [x] **SEC-02**: URL-routaus on yhtenäinen — `?nakyma=kartta` toimii kaikkialta (BottomNav, siirtymät, suorat linkit)
- [x] **SEC-03**: Supabase-tauluissa on RLS-politiikat — anon-avain sallii vain lukemisen
- [x] **SEC-04**: Käyttäjä näkee ystävällisen virhe- ja lataussivun (ei Next.js stacktrace tai tyhjää ruutua)

### Map & GPS

- [x] **MAP-01**: Käyttäjä voi pyytää sijaintinsa ja nähdä lähellä olevat palvelut kartalla; jos lupa evätään, Tampere-keskusta on hiljaa oletussijainti
- [x] **MAP-02**: Jokainen palvelukortti näyttää etäisyyden käyttäjästä ("1,2 km")
- [x] **MAP-03**: Karttakomponentti toimii `@vis.gl/react-google-maps` -kirjastolla (AdvancedMarker, ei double-load flashia)

### Data Architecture

- [x] **DATA-01**: Palveluiden aukioloajat haetaan automaattisesti Google Place Details -haulla ja tallennetaan Supabaseen
- [x] **DATA-02**: Tietokanta kattaa useita lajikategorioita: kuntosali, padel, uinti, jooga, kiipeily, jääkiekko ja muut
- [x] **DATA-03**: Tampere-alueen top 20 palvelun kertakäyntihinta on syötetty manuaalisesti Supabaseen
- [x] **DATA-04**: Supabase-schema sisältää kentät: `hinta_kuvaus text`, `aukioloajat jsonb`, `lajit_lista jsonb`, `featured boolean`

### UI & Service Information

- [x] **UI-01**: Palvelukortti näyttää aukioloajat ilman klikkaamista
- [x] **UI-02**: Palvelukortti näyttää "Auki nyt" / "Suljettu" -badgen ja käyttäjä voi suodattaa vain avoinna olevat
- [x] **UI-03**: Palvelukortti näyttää "Kertakäynti OK" -badgen kun palvelu sallii kertakäynnin
- [x] **UI-04**: Palvelun profiilisivu näyttää hinta- ja aukioloajat kattavasti

### AI Widget

- [x] **AI-01**: Etusivun AI-widget näyttää sääpohjaisen suosituksen (Claude Haiku + Open-Meteo) suomeksi
- [x] **AI-02**: AI-widget latautuu ei-blokkaavasti — staattinen fallback näkyy heti, AI-teksti täydentää kun valmis
- [x] **AI-03**: AI-widgetin vastaus tallennetaan `sessionStorage`-välimuistiin — saman päivän uudelleenlataukset eivät hae API:sta uudestaan

### Ad Placeholder

- [x] **ADS-01**: Supabasessa on `featured boolean` -kenttä palveluille — mainostilan infrastruktuuri varattuna
