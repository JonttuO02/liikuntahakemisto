## Milestone Summary

**Key Decisions:**

- TO DO replaces suosikit entirely — heart icon → bookmark icon across all UI
- image_url is a manual field in paikat table; placeholder shown if null
- "Näytä kartalla" centers on venue coordinates, not user GPS; bottomsheet stays closed
- Bottom sheet starts closed on homepage load, animates open immediately (Phase 20)
- sessionStorage key 'etusivu-scroll-state' persists scroll+filter state for back-nav (Phase 20)
- kiinnostukset sent in AI POST body; cache key includes sorted join for personalization (CR-01 fix)
- isAuthReady guard: AI effect waits for auth to resolve before first fetch (CR-02/WR-02 fix)
- kiinnostukset validated against lajiKonfig keys server-side (IN-01 fix)
