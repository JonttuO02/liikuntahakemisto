## Milestone Summary

**Key Decisions:**

- APIProvider placed in layout.tsx — Maps JS API loads once at app startup
- useGPS auto-requests location on mount; status starts as 'requesting' not 'idle'
- @react-google-maps/api removed; codebase fully on @vis.gl/react-google-maps
- distancesMap keyed by venue id, recomputed on GPS coords change via useMemo
- lib/aukiolo.ts is single source of truth for open-status + grouped-hours logic
- "Auki nyt" filter is lenient: null aukioloajat passes through (shows "Aukioloajat tuntematon")
- HoursTable.tsx is 'use client' island — today-highlighting uses browser local time
- ANTHROPIC_API_KEY is server-only env var — SDK reads it automatically, never NEXT_PUBLIC_
- Open-Meteo failure defaults to temp=15, code=0 so Claude still runs with sensible values
- Claude failure returns time-based Finnish fallback — widget is always non-blocking HTTP 200
- sessionStorage cache key scoped to calendar day (YYYY-MM-DD) — always cached regardless of fallback status

**Issues Resolved:**

- Double-load flash with @react-google-maps/api → migrated to @vis.gl
- Etusivu typewriter animation replaced with non-blocking fetch pattern
- sessionStorage cache write was skipped on fallback:true → fixed to always cache (AI-03)
- page.tsx select was missing aukioloajat and hinta_kuvaus columns → fixed in 05-01

**Technical Debt:**

- Data ops must be run manually: /api/admin/sync-paikat + scripts/seed-hinnat.ts (no CI automation)
- Testi 4 (AI sääkonteksti) UAT ohitettu — vaatii Claude API -krediittejä
- GPS-tarkkuusrengas puuttuu käyttäjän sijaintimerkistä (vain staattinen piste)
