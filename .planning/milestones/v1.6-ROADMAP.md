## Milestone Summary

### Key Decisions

| Decision | Rationale |
|----------|-----------|
| next-intl without-routing | Säilyttää URL-sopimuksen (`/` ja `/?nakyma=lista`); ei URL-pohjaista locale-routingia |
| NEXT_LOCALE-cookie (ei localStorage) | SSR-yhteensopiva — middleware voi lukea ennen renderöintiä |
| SVG path-string (ei @svgr/webpack) | Turbopack-yhteensopiva; ei webpack-plugin -riippuvuutta |
| lib/sportIcons.tsx yksi rekisteri | lib/lajit.ts puhdas — SPORT_ICONS poistettu, vain laji-konfig jäljellä |
| Kielivalitsin profiilisivulla | Eksplisiittinen vaihto; ei auto-detection — simpler UX for MVP |
