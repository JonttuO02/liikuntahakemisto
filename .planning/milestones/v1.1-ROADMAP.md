## Milestone Summary

**Key Decisions:**
- Supabase Auth uses per-request `createServerClient` — never module-scope singleton
- `toggleSuosikki` calls `getUser()` on each invocation — avoids stale auth state from closure
- AI route: GET for anonymous users, POST with `suosikkiNimet[]` for signed-in; cache key includes count suffix
- HeartButton is a standalone client component — manages own subscription lifecycle
- Map focus URL: `/?id=<paikka_id>` — `setValittu` NOT called, only map pans/zooms (sheet stays closed)
- PWA must use Serwist (@serwist/next + serwist) — next-pwa and @ducanh2912/next-pwa are abandoned
- Service worker excludes `_rsc` requests and is disabled in dev mode
- `themeColor` lives in `viewport` export (Viewport type), NOT metadata — avoids Next.js 14 deprecation warning
- `other: { mobile-web-app-capable: yes }` replaces deprecated `appleWebApp.capable: true`
- Offline fallback page uses plain `<a href>` not Next.js `<Link>` — full navigation required so SW can intercept when client-side router is unavailable offline
- AdvancedMarker children-based pin model (img child) preserves pinUrl SVG output unchanged
- MapStyleController removed — day/night styles baked into Cloud Console Map IDs

**Issues Resolved:**
- city filter off-by-one: `deriveKaupungit` threshold must be > 2 not > 1 (sentinel 'Kaikki' always prepended)
- RLS INSERT needs `WITH CHECK` not `USING` for favorites table
- `app/sw.ts` excluded from root tsconfig (webworker globals not needed in dom context)
- `swTsconfigPath` option unrecognized in @serwist/next@9.5.11 — removed
- Next.js 14 deprecation: `appleWebApp.capable: true` → `other: { mobile-web-app-capable: yes }`

**Issues Deferred:**
- `/suosikit` page (Suosikkipaikat for signed-in users) — deferred to v1.2
- Sydän-nappi session edge cases (see auth-debug-phase9.md memory) — defer to v1.2

**Technical Debt Incurred:**
- sync-paikat hardcodes kaupunki column logic — needs parameterization before further city syncs
- Google OAuth callback URL needs manual setup in Google Cloud Console + Supabase dashboard
