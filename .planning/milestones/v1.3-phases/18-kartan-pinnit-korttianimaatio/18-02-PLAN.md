**B. Add groupByCoords logic** as a new useMemo immediately after the `paikatKartalla` useMemo block (after line 318). The useMemo takes `paikatKartalla` as its dependency and returns `mapItems`:

The grouping key is `Math.round(lat * 10000) + ',' + Math.round(lng * 10000)` (this rounds to ±0.0001° precision as specified in D-06).

The return type is an array of discriminated union items:
- `{ type: 'single'; paikka: Liikuntapaikka & { latitude: number; longitude: number } }` — for keys with exactly 1 venue
- `{ type: 'cluster'; lat: number; lng: number; items: (Liikuntapaikka & { latitude: number; longitude: number })[] }` — for keys with 2+ venues, using the average lat/lng of the group as the pin position

Implementation pattern:
```
const mapItems = useMemo(() => {
  const groups = new Map<string, typeof paikatKartalla>()
  for (const p of paikatKartalla) {
    const key = Math.round(p.latitude * 10000) + ',' + Math.round(p.longitude * 10000)
    const group = groups.get(key) ?? []
    group.push(p)
    groups.set(key, group)
  }
  return Array.from(groups.values()).map(items =>
    items.length === 1
      ? { type: 'single' as const, paikka: items[0] }
      : {
          type: 'cluster' as const,
          lat: items.reduce((s, p) => s + p.latitude, 0) / items.length,
          lng: items.reduce((s, p) => s + p.longitude, 0) / items.length,
          items,
        }
  )
}, [paikatKartalla])
```
