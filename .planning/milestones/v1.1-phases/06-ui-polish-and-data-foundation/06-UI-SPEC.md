> Generated by gsd-ui-researcher. Consumed by gsd-planner, gsd-executor, and gsd-ui-auditor.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn — Tailwind v3 + @base-ui/react) |

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `gap-1`, `p-1` | Icon gaps, badge inner padding |
| sm | 8px | `gap-2`, `p-2` | Badge padding, inline element gaps |
| md | 16px | `p-4`, `gap-4` | Card internal padding |
| lg | 24px | `p-6`, `gap-6` | Profile page row padding |
| xl | 32px | `p-8`, `gap-8` | Profile page card padding (`sm:p-8`) |
| 2xl | 48px | `pt-10` | List hero top padding |
| 3xl | 64px | `pb-16` | Wave divider clearance |

Exceptions:
- Filter pill height: `py-2 px-4` (8px / 16px) — not a full scale step but established pattern
- Card bottom row separator: `pt-3` (12px) — replaces former `pt-2.5` (10px was off-scale)
- Touch targets: minimum 44px tall for all tappable controls (dropdowns, filter buttons, CTA)
- AI widget padding: `px-4 py-3` (16px / 12px) — replaces former `py-3.5` (14px was off-scale)
- Sponsoroitu badge: `py-1` (4px) — replaces former `py-0.5` (2px was off-scale)
- Price row gap: `gap-2` (8px) — replaces former `gap-1.5` (6px was off-scale)

**Source:** CLAUDE.md, direct inspection of PaikkaKortti.tsx and LiikuntapaikatLista.tsx

## Typography

**Declared sizes (4 maximum):**

| Role | Size | Weight | Line Height | Class / Usage |
|------|------|--------|-------------|---------------|
| Micro label / badge | 10px | 700 (bold) | 1 | `text-[10px] font-bold` — sport type badge, price badge, Sponsoroitu badge, profile row caps (`uppercase tracking-widest`) |
| Body / UI label | 14px | 400 (normal) | 1.625 (relaxed) | `text-sm leading-relaxed` — card descriptions, address rows, muted secondary text, card names, price display values |
| Subheading / price (profile) | 20px | 700 (bold) | 1 | `text-xl font-bold` — profile price row |
| Display heading | 30–36px (responsive) | 700 (bold) | tight | `text-3xl sm:text-4xl font-bold font-serif` — all H1 headings (lista page and profile page) |

**Active weights:** 400 (normal) and 700 (bold) only. Semibold (600) is not used in this phase — elements formerly at 600 are upgraded to 700 where emphasis is required, or kept at 400 where they are secondary.

**Weight assignment by role:**
- Bold (700): venue name in card, price values, micro badge labels, section headings, sport dropdown text
- Normal (400): addresses, descriptions, muted subtitles, "vain jäsenyys" text, city name in AI widget weather line

**Font family:** Inter for all UI text. `font-serif` (default system serif) for display headings and bold price values on the profile page — this is an existing project pattern; do not replace with Inter.

**Note on 60px removal:** The previous `text-6xl` (60px) declaration was collapsed into the responsive `text-3xl sm:text-4xl` display size. No heading in this phase requires a size beyond 36px.

**Source:** Direct inspection of PaikkaKortti.tsx, LiikuntapaikatLista.tsx, app/paikat/[id]/page.tsx, CLAUDE.md

## Color

| Role | Value | Tailwind | Usage |
|------|-------|----------|-------|
| Dominant (60%) | #ffffff | `bg-white` | Page backgrounds, card backgrounds, `--background` CSS var |

| Foreground primary | #111111 | `text-[#111111]` | Headings, active buttons, CTA |
| Foreground muted | rgba(17,17,17,0.45) | `text-[rgba(17,17,17,0.45)]` | Addresses, subtitles, secondary text |
| Foreground disabled | rgba(17,17,17,0.35) | `text-[rgba(17,17,17,0.35)]` | "Lisätään pian" placeholder |
| Accent — interactive | #111111 (black) | `bg-[#111111]` | Active filter pills, primary CTA buttons, active nav states |
| Accent hover | #333333 | `hover:bg-[#333333]` | Button hover state |
| Border default | rgba(0,0,0,0.07) | `border-[rgba(0,0,0,0.07)]` | Card separators, container borders |
| Border interactive | rgba(0,0,0,0.12) | `border-[rgba(0,0,0,0.12)]` | Input fields, outlined buttons |
| Open status | #16a34a | `bg-green-500 text-green-700` | "Auki nyt" indicator dot + text |
| Destructive | #dc2626 | `text-red-600` | Not present in this phase |

**Primary focal point:** Venue name in each card (bold, 14px, `text-[#111111]`). Secondary focal point: price row immediately below the name — price is bold and visually distinct from address/description text.

**Sport-type colors:** Defined exclusively in `lib/lajit.ts` via `lajiKonfig[laji].color`. Always applied via `style={{ backgroundColor: laji.color }}` — never hardcode hex values for sport badges in component JSX.

**Accent reserved for:**
- Active filter pill (sport dropdown selected state, price pills, "Auki nyt" toggle)
- Primary CTA buttons (map "Varaa →", any `bg-[#111111]` buttons)
- Active/checked toggle states

**New in Phase 6 — Sponsoroitu badge:**
- Background: `bg-amber-100` (#fef3c7)
- Text: `text-amber-700` (#b45309)
- Border: `border border-amber-200` (#fde68a)
- Size: `text-[10px] font-bold px-2 py-1 rounded-full`
- Amber is semantically correct for "sponsored" and does not conflict with the #111111 primary system. This is the only amber usage in the project.

**GDPR page:**
- Background: `bg-white` — no glassmorphism, no hero section
- Max-width container: `max-w-2xl mx-auto px-4`
- Heading color: `text-[#111111]`
- Body text color: `text-[rgba(17,17,17,0.65)] leading-relaxed`

**Navigation link:** Add a "Tietosuoja" text link to the NavBar (small, muted — `text-[10px] text-[rgba(17,17,17,0.45)]`) or as a footer link inside `LiikuntapaikatLista`. Do NOT add a BottomNav tab. ### UI-05 + UI-06: Price at Top of Card

**New card price layout — replaces current bottom-row price display:**

Price moves from the bottom row (right side of CTA row) to a dedicated position after the open-status row and before the address row. This makes pricing the 3rd piece of information after sport type + name + open status.

**Card section order (new):**
1. Badge row (sport pill + Sponsoroitu + Kertakäynti OK)
2. Venue name link
3. Open status indicator
4. **Price row (new position — moved from bottom)**
5. Address row
6. Description (line-clamp-2)
7. Bottom row (CTA button only — price removed from here)

**Price row visual spec:**

```tsx
{/* Walk-in price at top */}
{priceDisplay && (
  <div className="flex items-baseline gap-2">
    <span className="text-sm font-bold text-[#111111] tabular-nums">{priceDisplay}</span>
  </div>
)}
```

**Multiple prices:** If `hinta_kuvaus` contains line breaks (`\n`) or slash-separated values, each price appears on its own line at `text-sm font-bold`. Implementation: split on `\n` and map to `<span className="block">` children within the price `<div>`.

**"vain jäsenyys" fallback logic:**
- Show "vain jäsenyys" ONLY when `hinta_kuvaus` exists AND `hinta_kuvaus.toLowerCase().includes('jäsenyys')` is true
- Do NOT show "vain jäsenyys" when all price fields are null (use existing "Lisätään pian" fallback for null state)
- "vain jäsenyys" style: `text-sm text-[rgba(17,17,17,0.5)]` (muted, not bold — it is a constraint, not a selling point)

**Bottom row (after UI-06):** Bottom row retains only the CTA button — price `<div>` moves up. Distance string (`distanceStr`) remains in the bottom row right side.

### UI-08: Sport Filter as Single-Select Dropdown

**Replace:** The horizontal pill scroll (`flex gap-2 overflow-x-auto`) in `LiikuntapaikatLista.tsx` Row 1.

**Use:** Native `<select>` element. Reason: zero new packages, full keyboard accessibility, native mobile UX. Base-UI Select is an acceptable alternative but adds more markup for no functional gain here.

**Visual spec:**

```tsx
<select
  value={aktiivinen}
  onChange={e => setAktiivinen(e.target.value)}
  aria-label="Suodata lajin mukaan"
  className="h-10 rounded-full border border-[rgba(0,0,0,0.12)] bg-white px-4 text-sm font-bold text-[#111111] focus:outline-none focus:ring-1 focus:ring-[#111111] [transition:border-color_150ms_var(--ease-out)] cursor-pointer"
>
  {LAJIT_FILTTERI.map(l => (
    <option key={l} value={l}>{l}</option>
  ))}
</select>
```

`LAJIT_FILTTERI` from `lib/lajit.ts` remains the options source unchanged. The first option must be "Kaikki" (already the first item in the array).

**Placement:** The `<select>` replaces the entire pill scroll `<div>` in Row 1. The GPS "Etäisyydet" button remains in Row 1 as a sibling:

```
Row 1: [Sport dropdown]  [Etäisyydet button]
Row 2: [Price pills]  [N paikkaa count]
Row 3: [Auki nyt toggle]
```

**Accessibility:** The `<select>` is natively keyboard-accessible. Add `aria-label="Suodata lajin mukaan"` attribute.

### DATA-07: City Filter

**Location:** `LiikuntapaikatLista.tsx` only. Not in Etusivu map view.

**Placement:** New Row 0 above the existing Row 1 (sport dropdown), or co-locate with sport dropdown in Row 1 as a second `<select>`. Preferred: same row as sport dropdown for visual economy:

```
Row 1: [City dropdown]  [Sport dropdown]  [Etäisyydet button]
```

**Visual spec — city dropdown (identical pattern to sport dropdown):**

```tsx
<select
  value={aktiivKaupunki}
  onChange={e => setAktiivKaupunki(e.target.value)}
  aria-label="Suodata kaupungin mukaan"
  className="h-10 rounded-full border border-[rgba(0,0,0,0.12)] bg-white px-4 text-sm font-bold text-[#111111] focus:outline-none focus:ring-1 focus:ring-[#111111] [transition:border-color_150ms_var(--ease-out)] cursor-pointer"
>
  {kaupungit.map(k => (
    <option key={k} value={k}>{k}</option>
  ))}
</select>
```

**Null handling:** `kaupungit` derived via:
```tsx
const kaupungit = useMemo(
  () => ['Kaikki', ...Array.from(new Set(paikat.map(p => p.kaupunki).filter(Boolean).sort()))],
  [paikat]
)
```

`filter(Boolean)` excludes null/empty city values. Venues with null `kaupunki` remain in the list when "Kaikki" is selected but are excluded when a specific city is selected. Do NOT show a "Tuntematon" option.

**Filter composition:** City filter combines with existing sport, price, and auki filters via AND logic (same pattern as `matchesLaji`).

**Hero subtitle update:** The hardcoded `"Tampere · {paikat.length} paikkaa"` should update to reflect the active city filter: when a specific city is selected, show `"{aktiivKaupunki} · {suodatettu.length} paikkaa"`. When "Kaikki" is selected, show `"Kaikki kaupungit · {suodatettu.length} paikkaa"`.
