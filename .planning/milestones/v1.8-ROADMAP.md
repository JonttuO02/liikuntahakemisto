# Milestone v1.8: Yritysportaali v2 — Julkistaminen & UX

**Status:** ✅ SHIPPED 2026-06-11
**Phases:** 37–38
**Total Plans:** 9 (6 + 3)

## Overview

Turvallisuus- ja data-integriteettikorjauksia v1.7 yritysportaaliin. RSC guard kaikille `/business/*`-reiteille, data-integriteetti ja API-suojaukset tiukennettu, Postgres-triggerit atomiselle hyväksynnälle, ja verifikaatio-tikki julkaistuille paikoille kaikissa korteissa.

Phase 39 (Business User UX) oli alun perin osa v1.8:aa mutta siirrettiin v1.9:ään, koska se vaati auth-session eristyksen arkkitehtuurimuutoksen ensin.
