## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Supabase Auth | Sign-out action calls Supabase client in browser; clears sb-biz-* session cookies |
| BusinessNav → sb-biz-* only | BusinessNav must only use createBusinessBrowserClient — never the consumer client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-01 | Information Disclosure | BusinessNav sign-out | mitigate | Use createBusinessBrowserClient().auth.signOut() to clear sb-biz-* cookies only; consumer sb-* session is unaffected — isolated by cookie namespace |
| T-41-02 | Elevation of Privilege | BusinessNav links | accept | Nav links lead only to /business/* routes; middleware already guards all /business/* routes from unauthenticated access |
| T-41-03 | Tampering | i18n key injection | accept | i18n keys are static compile-time strings; no user input touches translation values |
| T-41-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase; all dependencies are already verified in package.json |
</threat_model>
