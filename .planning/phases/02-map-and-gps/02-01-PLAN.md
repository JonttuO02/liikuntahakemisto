    haversineKm(lat1, lng1, lat2, lng2): number
    - Earth radius 6371 km
    - Use atan2 form for numerical stability: 2 * atan2(sqrt(a), sqrt(1-a))
    - Arguments and return value are all plain numbers (no objects)

    formatDistance(km: number): string
    - km < 0.1 (less than 100 m): return '< 100 m'
    - km < 1 (100 m to 999 m): round to nearest 50 m, return e.g. '450 m'
    - km < 10 (1 km to 9.9 km): one decimal, Finnish comma, return e.g. '1,2 km'
    - km >= 10: round to integer, return e.g. '12 km'

    Create hooks/useGPS.ts:
    Export GPSStatus union type: 'idle' | 'requesting' | 'granted' | 'denied' | 'unavailable' | 'timeout'
    Export GPSState interface: { status: GPSStatus; coords: { lat: number; lng: number } | null; requestLocation: () => void }
    Export useGPS(): GPSState hook:
    - Initial state: status 'requesting', coords null (auto-requests immediately on mount)
    - requestLocation is a useCallback with empty deps
    - requestLocation first checks navigator.geolocation exists; if not, sets status 'unavailable' and returns
    - requestLocation sets status 'requesting', then calls getCurrentPosition with:
        enableHighAccuracy: true, timeout: 10_000, maximumAge: 30_000
    - On success: set coords { lat, lng }, set status 'granted'
    - On error code 1 (PERMISSION_DENIED): set status 'denied', coords null — map silently uses TAMPERE fallback
    - On error code 2 (POSITION_UNAVAILABLE): set status 'unavailable', coords null
    - On error code 3 (TIMEOUT): set status 'timeout', coords null
    - Default error branch: set status 'unavailable', coords null
    - AUTO-REQUEST ON MOUNT: add a useEffect(() => { requestLocation() }, []) so GPS is requested
      immediately when the component that uses useGPS mounts — no user button tap required.
    - Add 'use client' directive at top of file.
