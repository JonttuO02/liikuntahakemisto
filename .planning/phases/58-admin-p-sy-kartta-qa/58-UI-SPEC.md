# Phase 58 — UI Design Contract

> Visual and interaction contract for the "Sijainti" (location) map section added to `app/admin/[id]/page.tsx`. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** This phase adds zero new design primitives. It composes three already-built pieces — `Map`/`AdvancedMarker` (`@vis.gl/react-google-maps`), `SportPin`, `CalloutCard` — inside a container styled exactly like `SijaintiPicker.tsx`, following the existing "SectionLabel + glass card" pattern already used three times on this same page (Listakortti / Diagonaalikortti / Profiilisivu). The contract below exists to pin down the exact reuse so the executor does not improvise spacing, color, or interaction behavior.

## Interaction Contract

| Behavior | Spec |
|----------|------|
| Map type | `Map` from `@vis.gl/react-google-maps`, zoomable/pannable via standard Google Maps gestures (`gestureHandling="greedy"`, matching `SijaintiPicker.tsx`) — NOT a static image |
| Initial view | Centered on `{ lat: paikka.latitude, lng: paikka.longitude }`, `defaultZoom={15}` (fixed, no auto-fit-bounds — single pin only) |
| Pins shown | Exactly one `AdvancedMarker` containing `<SportPin laji={paikka.laji} />` — no clustering, no other venues, no user-location dot, no recenter button (unlike `SijaintiPicker.tsx` and `Etusivu.tsx`, this is a static single-venue viewer; GPS/recenter controls are out of scope) |
| Pin click | Toggles `CalloutCard` visibility (local component state, e.g. `useState<boolean>`) — same visual transition style as `Etusivu.tsx`'s pin→card swap is NOT required to be replicated (no AnimatePresence/zoom-level logic needed since there's only one marker and no clustering); a simple show/hide is sufficient |
| CalloutCard click | No `onClick` prop passed at all — omit the handler entirely (per D-08). Do not add `pointer-events-none`; the card should look identical to the main map's version, it simply has no wired behavior |
| Map background click | Optional: clicking the map background may dismiss an open `CalloutCard` (mirrors `Etusivu.tsx`'s `onClick={() => setValittu(null)}` pattern) — left to executor discretion, not a hard requirement |
| `mapId` | Use `process.env.NEXT_PUBLIC_GOOGLE_MAPS_MAP_ID` (same env var as `SijaintiPicker.tsx`) |
| `APIProvider` | None needed — already mounted globally in `app/layout.tsx` via `MapProvider` |

## Container & Layout Contract

Exact match to `SijaintiPicker.tsx`'s map container (`app/components/SijaintiPicker.tsx:115-122`):

```tsx
<div
  className="relative rounded-2xl overflow-hidden border border-[rgba(0,0,0,0.07)]"
  style={{ width: '100%', height: '320px' }}
>
  <Map
    mapId={MAP_ID}
    defaultCenter={{ lat: paikka.latitude, lng: paikka.longitude }}
    defaultZoom={15}
    gestureHandling="greedy"
    style={{ width: '100%', height: '320px' }}
  >
    <AdvancedMarker position={{ lat: paikka.latitude, lng: paikka.longitude }}>
      {/* SportPin + conditional CalloutCard, click toggles visibility, no onClick on CalloutCard */}
    </AdvancedMarker>
  </Map>
</div>
```

Placed inside the page's existing section pattern:

```tsx
<div className="flex flex-col gap-2">
  <SectionLabel>Sijainti</SectionLabel>
  {/* map container above */}
</div>
```

Width: fits the page's existing `max-w-2xl mx-auto` column — no separate width constraint needed.

Placement in JSX: between the "Toiminnot" (approve/reject) block and the "Listakortti" preview section, per D-03/code_context placement note — i.e. it becomes the first of the four preview-style sections, appearing before Listakortti.
