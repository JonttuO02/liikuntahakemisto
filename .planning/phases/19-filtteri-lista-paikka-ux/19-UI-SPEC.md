> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (custom glassmorphism) |
| Preset | not applicable |
| Component library | none (custom `.glass`, `.glass-btn`, `.glass-hover`, `.glass-nav` utilities) |

**Note:** This project uses a bespoke glassmorphism design system defined in `app/globals.css`. Do not introduce shadcn, Radix, or any external component library. All new UI elements must use the existing utility classes.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (`gap-1`, `p-1`) |
| sm | 8px | Compact element spacing (`gap-2`, `p-2`) |
| md | 16px | Default element spacing (`gap-4`, `px-4`) |
| lg | 24px | Section padding (`py-6`) |
| xl | 32px | Layout gaps (sheet section breaks) |
| 2xl | 48px | Major section breaks (empty state py) |
| 3xl | 64px | Page-level spacing |

Exceptions:
- DiagonaalKortti fixed height: `h-32` (128px) — established card height, do not change
- Pin button touch target: minimum `w-7 h-7` (28px) even though icon is `w-3.5 h-3.5` (14px)
- Pin button position: `bottom-3 left-3` (12px) — mirrors the left panel's existing `p-3` internal card padding for visual alignment
- AI widget padding: `py-4` (16px vertical) — increased from current `py-3.5` per D-11
- Karuselli bottom offset: `bottom: '5%'` — reduced from `'10%'` per D-12
- HANDLE_H: `44px` — existing constant for sheet tab visibility

| Role | Size | Weight | Line Height | Usage in Phase 19 |

## Interaction & Animation

All animation values follow the Emil Kowalski conventions established in CLAUDE.md.

### "Kertakäynti OK" Toggle Button

```
whileTap={{ scale: 0.96, transition: { duration: 0.1 } }}
```
- Same spec as existing filter pills in Etusivu.tsx line ~959
- No hover scale — conflicts with text layout
- Background color transitions at 150ms `var(--ease-out)`

### DiagonaalKortti — Pin Button

```
// No motion wrapper needed — parent card already handles hover scale
// Button itself uses whileTap on the parent motion.div
// Button tap: e.stopPropagation() + e.preventDefault() — no additional animation
```
- Touch target: minimum `w-7 h-7` centered flex, icon `w-3.5 h-3.5`
- Positioned: `mt-auto self-start` at the bottom of the left info panel flex column
- Only rendered when `paikka.latitude != null && paikka.longitude != null`
- Rendered as `<button>` sibling to `<Link>`, inside the `.absolute.inset-0` wrapper but OUTSIDE `<Link>` tag

### DiagonaalKortti — Image Panel Transition

- No animation on image load — deferred skeleton is out of scope (CONTEXT.md deferred)
- `loading="lazy"` on `<img>` tag
- No fade-in, no blur-up — plain load

### AI Widget — Two-Row Layout

New flex structure:
```
flex-col gap-1 px-4 py-4 shrink-0
├── Row 1 (flex items-center gap-2):
│   ├── weather emoji + temp + city (existing, unchanged rendering)
│   └── day/night toggle button (existing, unchanged)
└── Row 2 (flex-1):
    └── aiTeksti span (text-sm font-normal, wraps naturally, no truncate)
```
- Outer container class change: `flex items-center` → `flex flex-col` (breaking change from current single-row layout)
- Padding change: `py-3.5` → `py-4`
- `aiTeksti` span: remove `shrink-0`, allow natural wrap
- Loading state (aiTeksti === null): show single-row skeleton or omit row 2

### Karuselli — Card Size Reduction

```
// Before:
bottom: '10%'
// no max-height

// After:
bottom: '5%'
maxHeight: 160   // px, added as inline style on each motion.div card
```
- `CARD_W` fraction stays at `0.62` — only vertical footprint shrinks
- Cards feel ~30% shorter in visible area due to bottom offset reduction
- The `flex-1 relative min-h-0` container class on the wrapper is unchanged
- Mask gradient unchanged: `linear-gradient(to bottom, black 90%, transparent 100%)`

### Map Zoom Callback (onShowMap)

When pin button is tapped:
1. `e.stopPropagation()` — prevent Link navigation
2. `e.preventDefault()` — prevent Link navigation
3. `onShowMap?.(paikka)` — fires callback in Etusivu
4. Etusivu callback executes: `setSearchOpen(false)` + `setAutoZoomTarget({ lat: paikka.latitude!, lng: paikka.longitude! })` + `pendingValittuRef.current = paikka`
5. Sheet collapses to pill, map animates to venue coordinates, callout card opens (existing MapAutoZoom flow)

**Left info panel structural change (D-07, D-09, D-10):**

```
// Inside the left clip-path div — flex flex-col gap-1 p-3
<Link href={`/paikat/${paikka.id}`} className="absolute inset-0 block">
  {/* Sport pill, name, open status, price, distance — unchanged */}

{/* Pin button — outside Link, inside .absolute.inset-0 wrapper */}

  <button
    onClick={e => { e.stopPropagation(); e.preventDefault(); onShowMap?.(paikka) }}
    aria-label="Näytä kartalla"
    className="absolute bottom-3 left-3 z-20 w-7 h-7 glass-btn rounded-full
               flex items-center justify-center
               text-[rgba(17,17,17,0.5)] hover:text-[#111111]
               [transition:color_150ms_ease]"
  >
    <MapPin className="w-3.5 h-3.5" />
  </button>

```

Pin button positioning note: `absolute bottom-3 left-3 z-20` sits over the left info panel within the clip-path zone. It must have `z-20` to be above the Link's `z-10` inset block. The existing `distanceStr` row must be pushed up or removed from the bottom position to avoid collision — if `distanceStr` is present, the pin button floats over it; the distance string should move to be inline near the price row, or the button should only render when `onShowMap` is provided (not just `hasCoords`).

**Right panel structural change (D-04, D-05):**

```typescript
// Remove: staticMapsUrl function, API_KEY const, MAP_ID const, hasCoords variable
// Keep: laji.color fallback, SPORT_ICONS, Icon

// New right panel render:
{paikka.image_url ? (
  <img
    src={paikka.image_url}
    alt={`Kuva: ${paikka.nimi}`}
    className="w-full h-full object-cover"
    loading="lazy"
    onError={(e) => {
      const img = e.currentTarget
      img.style.display = 'none'
      const fallback = img.parentElement?.querySelector('[data-fallback]') as HTMLElement | null
      if (fallback) fallback.hidden = false
    }}
  />
) : null}
<div
  className="w-full h-full flex items-center justify-center"
  style={{ backgroundColor: laji.color }}
  aria-hidden
  data-fallback
  hidden={!!paikka.image_url}
>
  <Icon className="w-8 h-8 text-white opacity-80" />
</div>
```

`data-fallback` + `hidden` pattern: the fallback div is always rendered in the DOM but hidden when `image_url` is present. If the `<img>` fails to load, `onError` hides the img and removes `hidden` from the fallback div, revealing the sport-color background. When `image_url` is falsy, the img is not rendered and the fallback div starts visible (`hidden={false}`).

The `hasCoords` variable is still needed for the pin button render condition (D-09) but no longer needed for the right panel.
