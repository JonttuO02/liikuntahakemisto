## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, SheetRow `pt-4` |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Phase-specific values:
- SheetRow top padding: `pt-4` (16px) — matches every existing row in PaikkaSheet
- SheetRow icon-to-content gap: `gap-3` (12px) — matches existing SheetRow gap-3
- SheetRow icon container: `w-8 h-8` (32×32px) — matches existing SheetRow icon size
- Touch target minimum: 32px (icon-only glass-btn buttons in PaikkaSheet header use `w-8 h-8`)

Exceptions: none.

## Typography

Source: CLAUDE.md ("4 sizes only, 2 weights only").

| Role | Size | Weight | Line Height | Class |
|------|------|--------|-------------|-------|
| Micro / badge / SheetRow label | 10px | 700 (bold) | 1 | `text-[10px] font-bold uppercase tracking-widest` |
| Body / UI label / SheetRow content | 14px (text-sm) | 400 or 700 | 1.5 | `text-sm` or `text-sm font-bold` |
| Subheading / price display | 20px (text-xl) | 700 (bold) | 1.3 | `text-xl font-bold` |
| Display heading | 30px / 36px responsive | 700 (bold) | 1.2 | `text-3xl sm:text-4xl font-bold font-serif` |

Weights used: **400** (normal) and **700** (bold). Weight 600 (semibold) is never used — project-wide constraint.

Phase-specific typography notes:
- "Näytä kartalla" link text: `text-sm font-bold text-[#111111]` with `underline underline-offset-2` — matches existing `t('showOnMap')` link style on old page
- SheetRow label "SIJAINTI": `text-[10px] font-bold text-[rgba(17,17,17,0.4)] uppercase tracking-widest` — the exact SheetRow label pattern already used for Hours, Phone, Price rows

## Interaction Contracts

### DiagonaalKortti — card click behaviour

| Context | `onOpen` prop | Click behaviour |
|---------|---------------|-----------------|
| `Etusivu.tsx` card grid | `(p) => setValittu(p)` | Opens PaikkaSheet for `p` — no navigation |
| `Etusivu.tsx` TO DO overlay (line 1074) | `(p) => setValittu(p)` | Same — opens PaikkaSheet |
| `PreviewModal.tsx` (business side) | not passed | No-op element — no navigation, no action |
| `LivePreviewPane.tsx` (onboarding) | not passed | No-op element — no navigation |
| `app/admin/[id]/page.tsx` | not passed | No-op element — no navigation |

No-op implementation: replace `<Link href={...}>` invisible overlay with `<div className="absolute inset-0 block z-10" />` when `onOpen` is absent. Do not render a dead link.

Scale animations on DiagonaalKortti are **unchanged**:
- `whileHover={{ scale: 1.02, transition: { duration: 0.18, ease: 'easeOut' } }}`
- `whileTap={{ scale: 0.98, transition: { duration: 0.12, ease: 'easeOut' } }}`

### PaikkaSheet — open trigger unchanged

PaikkaSheet continues to be opened exclusively via `setValittu(paikka)` in Etusivu. No new trigger mechanism introduced. The existing `/?id=X` URL param mechanism (lines 431–758 of Etusivu) handles the "Näytä kartalla" link navigation — user lands on homepage centered on the venue with PaikkaSheet open.

### 404 behaviour

`/paikat/[id]` directory deleted from filesystem. Next.js App Router returns its default 404 page. No redirect, no custom `not-found.tsx` for this route. Requirement VENUEPAGE-04: satisfied by deletion alone.
