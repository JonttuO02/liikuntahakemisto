## Color

This project uses a monochrome system. All accent is `#111111` (black).

**Design system note:** `CLAUDE.md` documents an earlier indigo-based color system (`bg-indigo-600`, `text-indigo-950`, etc.). The running codebase diverged from that system and now uses the monochrome glass system described below. This UI-SPEC reflects the actual running implementation, not the CLAUDE.md indigo tokens. The executor must follow this spec, not CLAUDE.md's color section.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` / `#F8F8F8` | Page background (`bg-white`), hero sections |
| Secondary (30%) | glass utility | All cards, Row icon containers, nav — `glass` class from globals.css |
| Accent (10%) | `#111111` | Active filter pills, primary CTA buttons, "Auki nyt" toggle when active |
| Open status | `#16a34a` (green-700) / `#f0fdf4` (green-50) | "Auki nyt" badge text + background ONLY |
| Closed status | `rgba(17,17,17,0.45)` / `rgba(17,17,17,0.07)` | "Suljettu" badge text + background ONLY |
| Drop-in badge | `rgba(17,17,17,0.55)` / `rgba(17,17,17,0.06)` | "Kertakäynti OK" badge — muted, secondary to open/closed signal |
| Destructive | not applicable | No destructive actions in Phase 4 |
| Unknown hours | `rgba(17,17,17,0.35)` | "Aukioloajat lisätään pian" and "Aukioloajat tuntematon" note text |

Accent (`#111111`) reserved for: active sport filter pills, active price filter pills, active "Auki nyt" toggle, primary CTA button ("Varaa aika →"), "Auki nyt" toggle active state.

Sport badge colors are sourced exclusively from `lajiKonfig[laji].color` in `lib/lajit.ts`. Never inline sport colors.

## Component Inventory — New UI Elements

### 1. Open Status Badge (PaikkaKortti.tsx)

Position: Below venue name `<h3>`, above address row. Inserted as a new `<div>` in the existing `flex flex-col gap-2` layout.

**When open** (`aukioloajat` has today's entry and current time is within range):
```
"Auki nyt · 09:00–21:00"
```
- Container: `inline-flex items-center gap-2`
- Dot indicator: `w-1.5 h-1.5 rounded-full bg-green-500 shrink-0`
- Text: `text-xs font-bold text-green-700`
- No background pill — keep it light; the color alone signals status

**When closed** (today's entry exists but current time is outside range, OR today has no hours but other days do):
```
"Suljettu"
```
- Container: `inline-flex items-center gap-2`
- Text: `text-xs text-[rgba(17,17,17,0.45)]`
- No dot indicator

**When `aukioloajat` is null** (no data at all):
```
"Aukioloajat lisätään pian"
```
- Text: `text-xs text-[rgba(17,17,17,0.35)]`
- Matches existing `"Lisätään pian"` placeholder pattern exactly

Format details:
- Separator: middle dot ` · ` (U+00B7, with spaces)
- Time range: en-dash `–` (U+2013) between open and close times
- Times display as `HH:MM` (already stored in this format in `aukioloajat`)

### 2. Drop-in Badge (PaikkaKortti.tsx) — D-05

Position: Appended inline after the sport badge in the top badge row (row 1), separated by a small gap. Not a second row — keeps vertical density low.

Detection: `hinta_kuvaus?.toLowerCase().includes('kertakäynti')` — if true, render badge.

**Rendered as:**
```
"Kertakäynti OK"
```
- Container: `inline-flex items-center gap-1 text-xs font-bold px-2 py-1 rounded-full bg-[rgba(17,17,17,0.06)] text-[rgba(17,17,17,0.55)]`
- Deliberately muted — does not compete with sport badge color
- No icon (keeps it compact alongside the sport badge)

Placement rule: Sport badge always renders first; drop-in badge appears immediately after in the same `flex items-center gap-2 flex-wrap` row.

### 3. Price Display (PaikkaKortti.tsx and profile page) — D-06

**Card bottom row (right side):**
- Priority 1: `hinta_kuvaus` — render as-is: `text-sm font-bold text-[#111111] tabular-nums`
- Priority 2: `hintateksti(hinta_min, hinta_max)` — same styling as Priority 1
- Priority 3: Both null → `"Lisätään pian"` in `text-xs text-[rgba(17,17,17,0.35)]`

**Profile page Row:**
- Priority 1: `hinta_kuvaus` — render as plain paragraph: `text-sm text-[rgba(17,17,17,0.65)] leading-relaxed`
- Priority 2: `hintateksti(hinta_min, hinta_max)` — render as: `font-serif text-xl font-bold text-[#111111]`
- Priority 3: Both null → omit the Row entirely (no empty Row rendered)

### 4. "Auki nyt" Filter Toggle (LiikuntapaikatLista.tsx) — D-07

Position: A new Row 3 inserted between the existing Row 2 (price filters + count) and the card grid. The toggle occupies the full left side of its row.

**Inactive state:**
```
"Auki nyt"
```
- Classes: `shrink-0 inline-flex items-center gap-2 px-4 py-2 rounded-full text-sm font-bold glass-btn text-[rgba(17,17,17,0.6)] hover:text-[#111111] [transition:background-color_150ms_var(--ease-out),color_150ms_var(--ease-out)]`

**Active state:**
- Classes: replace `glass-btn text-[rgba(17,17,17,0.6)]` with `bg-[#111111] text-white`
- Matches active pattern of sport filter pills exactly

**Icon:** `Clock` from lucide-react, `w-3.5 h-3.5`, placed before label text.

**Animation:** `whileTap={{ scale: 0.95, transition: { duration: 0.1 } }}` — same as existing filter buttons. No hover scale.

**Lenient mode (D-08):** When toggle is active, venues with `aukioloajat === null` remain in the filtered list but their status row renders `"Aukioloajat tuntematon"` instead of the normal open/closed display. The `"Aukioloajat tuntematon"` text uses `text-xs text-[rgba(17,17,17,0.35)]`.

State: `const [aukinyt, setAukinyt] = useState(false)` added to the component's existing state block.

### 5. Weekly Hours Row (profile page `app/paikat/[id]/page.tsx`) — D-09, D-10

Position: New `<Row>` inserted after the location Row and before the phone Row in the existing `flex flex-col gap-5` content block.

**Row icon:** `Clock` from lucide-react, `w-5 h-5 text-[rgba(17,17,17,0.5)]` — matches icon styling of existing Rows.

**Row label:** `"Aukioloajat"` — uppercase via existing Row label `text-[10px] font-bold uppercase tracking-widest text-[rgba(17,17,17,0.4)]` pattern.

**Hours display format:** Grouped ranges — consecutive days with identical hours collapsed to Finnish abbreviation ranges.

Finnish day abbreviations (in order): `Ma`, `Ti`, `Ke`, `To`, `Pe`, `La`, `Su`

Day key mapping (aukioloajat JSON → Finnish abbreviation):
```
monday    → Ma
tuesday   → Ti
wednesday → Ke
thursday  → To
friday    → Pe
saturday  → La
sunday    → Su
```

Grouping examples:
- Ma–Pe 06:00–22:00
- La 09:00–18:00
- Su suljettu

Closed days render the day abbreviation range followed by `suljettu` (lowercase, no time range).

**Today highlight:** The group containing today's day abbreviation renders in `text-sm font-bold text-[#111111]`. All other groups render in `text-sm text-[rgba(17,17,17,0.65)]`.

**Layout:** Each group on its own line inside the Row's `<div>` children:
```tsx
<div className="flex flex-col gap-1">
  {groups.map(group => (
    <p key={group.key} className={isToday(group) ? 'text-sm font-bold text-[#111111]' : 'text-sm text-[rgba(17,17,17,0.65)]'}>
      {group.label} {group.hours}
    </p>
  ))}
</div>
```

**When `aukioloajat` is null:** Omit the Row entirely (no empty Row rendered; data is absent, not unknown on the profile page).

## Animation Contract

All new interactive elements follow Emil Kowalski principles from CLAUDE.md.

| Element | Animation | Spec |
|---------|-----------|------|
| "Auki nyt" toggle | whileTap | `scale: 0.95, transition: { duration: 0.1 }` |
| Open status badge | none | Static — no entrance animation |
| Drop-in badge | none | Static — no entrance animation |
| Weekly hours rows | none | Static — part of server-rendered content |
| Card grid re-render on filter | key change | `key={grid-${aktiivinen}-${aktiivHinta ?? 'all'}-${aukinyt}`} triggers stagger re-mount |

Rules:
- No spring physics on any new element
- No layout animations
- No y-movement on badges — they are inline within the card flex column
- AnimatePresence not needed for badge state changes (badge is always rendered in the same position)

## Implementation Notes for Executor

1. **Open status logic lives in PaikkaKortti** — compute `isOpen` and `todayHours` from `paikka.aukioloajat` using `new Date()` client-side. The component is already `'use client'`.

2. **Day key derivation:** `const DAYS = ['sunday','monday','tuesday','wednesday','thursday','friday','saturday']`; use `DAYS[new Date().getDay()]` to get today's key.

3. **Time comparison:** Parse `"HH:MM"` strings to minutes-since-midnight integers for `open` and `close`. Compare against current `hours * 60 + minutes`.

4. **Profile page is a Server Component** — hours grouping logic must run at render time using server-side `new Date()` (UTC offset awareness needed: Tampere is UTC+3 in summer). Use `Intl` or explicit offset.

5. **Grid key must include `aukinyt`** — update the existing `key` prop on the motion grid div from `key={grid-${aktiivinen}-${aktiivHinta ?? 'all'}}` to `key={grid-${aktiivinen}-${aktiivHinta ?? 'all'}-${aukinyt}}` to trigger stagger re-animation on filter toggle.

6. **Empty state action** — the "Tyhjennä haku" button must also reset `aukinyt` to `false` when the "Auki nyt" filter is active and produces zero results.

7. **Drop-in badge wrapping** — the top badge row must become `flex items-center gap-2 flex-wrap` to accommodate both sport badge and drop-in badge without overflow on narrow cards.

8. **CTA copy change** — PaikkaKortti.tsx booking link label must be updated from any existing shorter variant to `"Varaa aika →"` to match the profile page CTA and the verb+noun convention.
