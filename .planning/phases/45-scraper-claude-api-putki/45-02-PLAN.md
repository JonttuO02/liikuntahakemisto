    File header: // Server-only. Never import in client components.

    Imports: import sharp from 'sharp'

    Export ScrapeResult interface with fields: logoUrls (string[]), logoBuffers (Buffer[]),
    colors (string[]), htmlSnippet (string).

    Internal helper toPngBase64(buffer: Buffer): Promise<Buffer | null> — wraps
    sharp(buffer).resize(512, 512, { fit: 'inside', withoutEnlargement: true }).png().toBuffer()
    in try/catch; returns null on error (Pitfall 8: invalid SVG favicon).

    Export scrapeWebsite(url: string): Promise<ScrapeResult>:
    1. Fetch HTML: fetch(url, { headers: { 'User-Agent': 'Mozilla/5.0 (compatible; AktiiviBot/1.0)' }, signal: AbortSignal.timeout(10000) }). If response is not ok, throw new Error('Sivua ei saatu ladattua: ' + url).
    2. Parse theme-color: regex /<meta\s+name=["']theme-color["']\s+content=["'](#[0-9a-fA-F]{3,6})["']/i on html. Collect match into colors array if found.
    3. Parse CSS stylesheet links: regex /<link[^>]+rel=["']stylesheet["'][^>]+href=["']([^"']+\.css[^"']*)["']/gi — collect up to 3 href values. Resolve relative URLs against the base url using new URL(href, url).href. Fetch all 3 in parallel with Promise.all, each with AbortSignal.timeout(5000), errors silently return ''.
    4. Extract :root hex vars from each CSS text: regex /--[\w-]+\s*:\s*(#[0-9a-fA-F]{3,6})\b/g — push all matches into colors array. Deduplicate colors with Array.from(new Set(colors)).
    5. Collect logo candidates:
       a. favicon: <link rel="icon"> or <link rel="shortcut icon"> href value, plus '/favicon.ico' as fallback. Resolve to absolute URL.
       b. og:image: <meta property="og:image" content="..."> value.
       c. img elements whose src, alt, or class contains "logo" (case-insensitive): regex /<img[^>]+>/gi, then check each tag's src/alt/class attributes.
       Collect in priority order a→b→c, deduplicate, take first 5.
    6. Fetch each logo candidate URL (AbortSignal.timeout(5000), errors skip candidate). Convert each fetched buffer with toPngBase64. Skip (do not include in logoBuffers) any candidate where toPngBase64 returns null.
    7. Return { logoUrls (original URL strings of successful candidates), logoBuffers (converted PNG Buffers), colors, htmlSnippet: html.slice(0, 8000) }.

    Error logging: console.error('[branding/scraper] error:', err) in catch blocks.
