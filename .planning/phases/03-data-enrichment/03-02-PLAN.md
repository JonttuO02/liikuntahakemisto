    Note about dotenv import: The project may or may not have dotenv as a direct

    If dotenv is in package.json (as any dependency): use the import as written above.
    If dotenv is NOT in package.json: replace the dotenv import block with:
    ```typescript
    import { readFileSync } from 'fs'
    import { resolve } from 'path'
    // Manual .env.local loader — avoid adding dotenv dependency for a one-off script
    try {
      const envPath = resolve(process.cwd(), '.env.local')
      const lines = readFileSync(envPath, 'utf-8').split('\n')
      for (const line of lines) {
        const [key, ...rest] = line.split('=')
        if (key && rest.length > 0 && !process.env[key.trim()]) {
          process.env[key.trim()] = rest.join('=').trim().replace(/^["']|["']$/g, '')
        }
      }
    } catch {
      // .env.local not found — rely on environment variables already being set
    }
    ```
