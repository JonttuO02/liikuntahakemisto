Define and export three things:

1. BrandingResult type (per D-PA-02 and the GET /api/business/analyze-website response shape):

```
export type BrandingResult = {
  status: 'pending' | 'analyzing' | 'analyzed' | 'failed'
  logo_url: string | null
  logo_type: string | null
  colors: string[] | null
  raw_analysis: {
    prices: Array<{ label: string; price: string }>
    opening_hours: Array<{ day: string; open: string; close: string }>
    website_url: string
  } | null
  error_message: string | null
}
```

2. getContrastColor utility (per D-BR-03) using the YIQ formula:
- Accepts a hex string (with or without leading #)
- Strips '#', parses R/G/B as 2-char hex segments
- Computes YIQ = (r * 299 + g * 587 + b * 114) / 1000
- Returns '#000000' when yiq >= 128, '#ffffff' otherwise
- Return type is '#000000' | '#ffffff'
- Handle malformed input safely: if parseInt returns NaN for any channel, treat as 0

3. buildBrandingPreview helper (per D-ES-02). Signature:
   buildBrandingPreview(paikkaBase: PaikkaBase, brandingResult: BrandingResult, draftPaikkaId: number): Liikuntapaikka

   Import PaikkaBase from '@/lib/onboardingUtils' and Liikuntapaikka from '@/lib/types'.
   Import hinnastaToHintaKuvaus from '@/lib/onboardingUtils'.

   Logic:
   - id: draftPaikkaId
   - nimi/laji/osoite/kaupunki/latitude/longitude: from paikkaBase (never from branding)
   - logo_url: brandingResult.logo_url (may be null — DiagonaalKortti handles null with Building2 fallback per D-BR-04)
   - colors[0] is used externally by DiagonaalKortti via the brandColor prop; buildBrandingPreview does NOT embed colors into Liikuntapaikka fields — colors are passed separately as a prop
   - hinta_kuvaus: if brandingResult.raw_analysis?.prices has entries, map them to {kategoria: price.label, hinta: price.price, lisatieto: ''} and pass through hinnastaToHintaKuvaus; otherwise ''
   - aukioloajat: if brandingResult.raw_analysis?.opening_hours has entries, convert the Array<{day,open,close}> to Record<string,{open,close}> keyed by day string; otherwise null
   - varauslinkki: brandingResult.raw_analysis?.website_url || null
   - kuvaus: null
   - puhelin: null
   - hinta_min: null
   - hinta_max: null
   - image_url: null
   - photo_urls: null
   - featured: false
   - business_managed: true (preview should show the verification badge)

   The opening_hours conversion: the API returns day strings as English weekday names (e.g. "monday", "tuesday"). These match the storage key format that aukioloajat Record uses. Map each entry: { [entry.day]: { open: entry.open, close: entry.close } }.
