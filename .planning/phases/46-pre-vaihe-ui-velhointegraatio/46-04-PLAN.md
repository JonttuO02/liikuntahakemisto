Internal state machine (per D-PU-01, D-PU-02, D-PU-03, D-PU-04):
  type Phase = 'checking' | 'url-input' | 'analyzing' | 'preview' | 'error' | 'timeout'

  'checking' → on mount, GET /api/business/analyze-website:
    status === 'analyzed' → set brandingResult + go to 'preview'
    status === 'analyzing' → go to 'analyzing' (starts poll loop)
    status === 'pending' or 'failed' or no row → go to 'url-input'

  'url-input' → user fills URL + submits:
    POST /api/business/analyze-website with { url }
    On success → go to 'analyzing'
    On error → show inline error, stay in url-input

  'analyzing' → poll loop (D-PU-02):
    Poll GET every 2000ms, max 30 tries
    status === 'analyzed' → set brandingResult + go to 'preview'
    status === 'failed' → go to 'error'
    tries exhausted (still 'analyzing') → go to 'timeout'
    Ohita button always visible → calls onSkip()

  'preview' → shows logo + colors + prices + hours (D-ES-01):
    "Jatka velhoon →" → calls onConfirm(brandingResult)
    "Analysoi uudelleen" link → go to 'url-input' (reset brandingResult to null)

  'error' → (D-PU-03):
    Shows: generic Finnish error message + "Yritä uudelleen" (go to 'url-input') + "Ohita" (calls onSkip)

  'timeout' → (D-PU-04):
    Shows: "Analyysi kestää odotettua kauemmin — yritä uudelleen tai jatka manuaalisesti"
    + "Yritä uudelleen" (go to 'url-input') + "Ohita" (calls onSkip)

On mount effect (checking phase):
  Call GET /api/business/analyze-website with Bearer token.
  If fetch fails or returns non-ok → go to 'url-input'.
  Parse JSON as BrandingResult.
  if data.status === 'analyzed' → setBrandingResult(data) + setPhase('preview')
  else if data.status === 'analyzing' → setPhase('analyzing')
  else → setPhase('url-input')
  No deps (run once). Cleanup: ignore stale responses.

Polling effect (triggers when phase === 'analyzing'):
  Use useRef<ReturnType<typeof setInterval> | null>(null) for intervalRef.
  Use useRef<number>(0) for tryCountRef.
  On phase entering 'analyzing': reset tryCountRef.current = 0, start setInterval(poll, 2000).
  poll() function:
    tryCountRef.current += 1
    if tryCountRef.current > 30 → clearInterval, setPhase('timeout'), return
    fetch GET /api/business/analyze-website with token
    if data.status === 'analyzed' → clearInterval, setBrandingResult(data), setPhase('preview')
    if data.status === 'failed' → clearInterval, setPhase('error')
    (otherwise keep polling)
  Cleanup: clearInterval on unmount or phase change.

URL submit handler (handleSubmit):
  Basic validation: if url.trim() is empty or doesn't start with http:// or https://, set urlError and return.
  Set submitting=true, urlError=null.
  POST /api/business/analyze-website with { url: url.trim() } and Bearer token.
  On non-ok: set urlError based on status (400 → 'Tarkista URL-osoite'; 403 → 'Ei käyttöoikeutta'; default → 'Analyysi ei onnistunut. Yritä uudelleen.').
  On ok: setPhase('analyzing').
  Always: setSubmitting(false).
