## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between swatch and its selected-checkmark overlay; gap inside gallery checkbox badge |
| sm | 8px | Gap between logo radio cards; gap between color swatches in the swatch row |
| md | 16px | Default gap between sections (matches existing `gap-6`→ see note); gap inside gallery grid cells |
| lg | 24px | Section-to-section gap in the `'preview'` phase render (existing `flex flex-col gap-6` container — treat as 24px) |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Touch targets for logo-radio-card and gallery-checkbox-thumbnail must be at least 44×44px tappable area even though the visual thumbnail may render smaller (e.g. a 64px thumbnail already clears this; ensure the checkbox/radio hit-area wraps the full thumbnail, not just a small icon corner).
- Color swatch button: 32px diameter (`w-8 h-8`, matches existing read-only swatch styling in `AnalysoiSivusto.tsx` line 370) but wrap in a min-44px tap target via padding on the button element, not by growing the visible swatch.

## Typography

Matches CLAUDE.md's 4-size, 2-weight system exactly — no new sizes introduced.

| Display heading | not used in this phase | — | — |

2 weights only: 400 (regular body/hex text) and 700 (bold — labels, selected states, buttons). Never introduce 600.

## Color

Matches CLAUDE.md's existing glassmorphism palette exactly — no new tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (`bg-white`) | Page/card background — already the `.glass` surface in `AnalysoiSivusto.tsx` |
| Secondary (30%) | `rgba(255,255,255,0.60–0.95)` (`.glass`) | The existing `glass rounded-2xl` card wrapping the whole preview phase; gallery grid cell background |
| Accent (10%) | `#111111` (`bg-[#111111]` / `text-[#111111]`) | Reserved for: selected-state ring/border on the chosen logo card; selected-state ring/border on the chosen color swatch; the "Hyväksy ja lähetä" and "Jatka velhoon →" primary buttons; the checkmark badge on selected gallery thumbnails; focus/active text on slot labels ("Tausta"/"Aksentti") when a value is assigned |
| Destructive | `#dc2626` (`text-red-600`) | Reserved for: validation error text only (e.g. "Valitse enintään 5 kuvaa", PATCH failure message) — no destructive *actions* exist in this phase's picker UI (no delete) |

Accent reserved for: selected logo card ring, selected color swatch ring, selected gallery thumbnail checkmark badge, primary CTA buttons ("Hyväksy ja lähetä", "Jatka velhoon →", "Analysoi sivusto"). Never apply accent to unselected/idle states — those stay in muted/border-default tones (`rgba(17,17,17,0.45)` text, `rgba(0,0,0,0.07)` border) so the one accent use per element type reads as a clear "this is chosen" signal, not decoration.

Second semantic color: none beyond destructive — this phase has no separate warning/info color. The amber "Sponsoroitu" badge token is unrelated and not used here.

## Component Inventory (new for this phase)

Not part of the template's fixed sections, but required for planner/executor precision given this phase's UI complexity:

| Component | Structure | Notes |
|-----------|-----------|-------|
| Logo picker | Horizontal scrollable row (or wrap grid if ≤4) of radio-style cards, each `border border-[rgba(0,0,0,0.12)] rounded-lg p-2` containing the candidate logo image (`h-12 w-auto object-contain`, reuses existing logo `<img>` styling) + the candidate's `type` as a small caption. Selected card gets `border-[#111111] ring-2 ring-[#111111]` (accent). Click anywhere on the card selects it — full card is the tap target, not just a tiny radio dot. Renders only when `logo_candidates.length > 0`; if `logo_candidates.length === 1`, still render the single card pre-selected (no different code path — keeps "explicit pick, not silent" semantics from success criterion 1 even at N=1). |
| Color picker | Two rows: (1) swatch row — up to 6 buttons, each `w-8 h-8 rounded-full border border-[rgba(0,0,0,0.07)]` (existing swatch style), selected swatch (matches current background OR accent slot value) gets `ring-2 ring-[#111111] ring-offset-2`; (2) slot row — two labeled mini-cards side by side ("Tausta" / "Aksentti"), each showing a `w-6 h-6 rounded-full` preview of its current color + the hex value in `text-sm`, tappable to "arm" that slot for the next swatch click. Custom hex input sits below both rows, always visible. |
| Gallery picker | CSS grid (`grid grid-cols-4 gap-2` or similar — match existing `flex flex-wrap gap-2` thumbnail pattern from `StepMediat.tsx`), each cell a `w-16 h-16` (or larger, e.g. `w-20 h-20` for the dedicated picker context — Claude's discretion within the 4px grid) thumbnail with a checkbox overlay (top-right corner badge, `bg-[#111111] text-white rounded-full`, checkmark icon when selected, matches the existing delete-button (`×`) corner-badge visual pattern in `StepMediat.tsx` lines 390/403/450/463 but with a check icon instead of `×` and no destructive action). Selected count shown above or below the grid. Disables (visually dims, `opacity-50`, non-clickable) unselected thumbnails once 5 are already selected. |
| Quick-accept button | Second `PrimaryButton`-style button placed next to "Jatka velhoon →" in the existing footer row — both share the same visual weight (both are `bg-[#111111]` filled), distinguished only by label text, not by color hierarchy (avoids implying one is "more correct" than the other per D-02's equal-footing intent). On mobile narrow widths, stack vertically with 8px gap rather than overflow. |

## Animation

Follows CLAUDE.md's Emil Kowalski principles exactly — no new animation patterns introduced.

| Interaction | Spec |
|-------------|------|
| Logo card / color swatch / gallery thumbnail selection | No motion needed beyond instant CSS class swap (border/ring color change) — selection state changes are not worth animating per "never animate for decoration" rule. If any feedback is desired, use `whileTap={{ scale: 0.95 }}` only (matches existing filter-button pattern), no hover scale. |
| PATCH autosave in-flight indicator | Small inline `Spinner` (existing component, `className="w-4 h-4"`) next to the section header during the autosave request — fades in/out via `AnimatePresence` `opacity` only, `duration: 0.15` (matches existing error-message fade pattern in `StepMediat.tsx`/`AnalysoiSivusto.tsx`) |
| Quick-accept button loading | Reuse existing `PrimaryButton`'s `loading` prop (renders `<Spinner className="w-4 h-4" />` inline before label) — already implemented, no new animation code needed |
| Section appearance (logo/color/gallery blocks mounting once `brandingResult` resolves) | No entrance animation — these render as part of the existing `'preview'` phase block, which itself has no enter animation in current code; do not add one (consistent with existing static reveal) |
