## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → PATCH /api/business/branding | Authenticated business client sends selection values; body fields are untrusted and cross into a service-role DB write |
| stored business_branding row → response | Server reads its own analysis candidates to validate selections |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-01 | Spoofing | PATCH auth | mitigate | `supabaseAdmin.auth.getUser(token)` at route entry; `business_account_id` taken from verified JWT, never from body (copied verbatim from save-step) |
| T-48-02 | Elevation/IDOR | PATCH ownership | mitigate | `business_paikka_links` `.eq(business_account_id).eq(paikka_id)` ownership-only → 403; a business cannot write branding for a venue it does not own. (Ownership-only, NOT claim_status='approved', matching save-step/submit — onboarding venues are 'pending' until submit; an approved-only filter would deny legitimate first-time onboarders. Satisfies ROADMAP success criterion 4 without breaking the flow.) |
| T-48-03 | Tampering | AI-sourced color/gallery membership | mitigate | Membership validation: AI-sourced color hex must exist in stored `colors`; every submitted `image_urls` entry must exist in stored `image_urls` → 400 on miss. Prevents claiming another business's analysis result or injecting unvalidated values |
| T-48-04 | Tampering | custom color hex | mitigate | Custom-override hex constrained to `/^#[0-9a-fA-F]{6}$/`; rejects script/data-URI/oversized values before DB write |
| T-48-05 | Denial of Service | oversized gallery array | mitigate | Reject `image_urls.length > 5` with 400 before any DB call |
| T-48-13 | Tampering / IDOR | logo URL injection into public venue identity | mitigate | Submitted `selected_logo_url` must match a `logo_candidates[].url` entry on the business's OWN stored row → 400 on miss. This is the single server-side gate before the same validated value flows (via Plan 03) into `media_urls.logo` and onward to `liikuntapaikat.logo_url` at submit. Closes the path where a malicious client sets an arbitrary URL as the venue's public logo (satisfies ROADMAP success criterion 4 + D-08). |
| T-48-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages introduced in this plan; no install task → gate not triggered |
</threat_model>
