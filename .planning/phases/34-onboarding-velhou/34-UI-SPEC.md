## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inline padding |
| sm | 8px | Input row gaps, toggle-to-label spacing |
| md | 16px | Card internal padding, form field vertical gaps |
| lg | 24px | Wizard step card padding (`p-6`), section gaps |
| xl | 32px | Step content top padding, preview card row gap |
| 2xl | 48px | Page vertical centering padding |
| 3xl | 64px | Page-level breathing room on desktop |

Exceptions:
- Touch targets for "Auki"-toggles and day-row tap areas: minimum 44px tall.
- Upload drop zone minimum height: 96px (provides adequate drag target).
- Progress bar indicator circles: 32px diameter (multiples-of-4 safe, matches 8-point grid).

Source: CLAUDE.md spacing conventions; exceptions derived from CONTEXT.md D-09 and D-15.

## Typography

Project enforces exactly 4 sizes and 2 weights. No new sizes or weights may be introduced.

| Role | Size | Tailwind | Weight | Line Height | Usage in Phase 34 |
|------|------|----------|--------|-------------|-------------------|
| Micro / badge | 10px | `text-[10px]` | 700 (bold) | 1.2 | Step number in progress circles, "JO HALLITTU" caps label, category caps labels, upload count badge |
| Body / UI label | 14px | `text-sm` | 400 or 700 | 1.5 | Form field labels, helper text, input placeholder text, pricing row labels, opening-hours day names, error messages, "Seuraava" / "Edellinen" button text |
| Subheading | 20px | `text-xl` | 700 (bold) | 1.2 | Step title inside each wizard card (e.g. "Paikka", "Mediat", "Hinnasto") |
| Display heading | 30–36px | `text-3xl sm:text-4xl` | 700 (bold) | 1.2 | Not used in wizard steps; reserved for page hero if added later |

Font weight rule: 400 (normal) and 700 (bold) only. Weight 600 (semibold) is forbidden.

## Color

| Role | Value | Tailwind / class | Usage |
|------|-------|-----------------|-------|
| Dominant (60%) | `#ffffff` | `bg-white` | Page background, input field fill |
| Secondary (30%) | `rgba(255,255,255,0.60–0.95)` | `.glass` | Wizard step cards, progress bar container, pricing rows, upload drop zone |

| Destructive | `#dc2626` | `text-red-600` | Inline field validation errors, step-level error messages |

Accent reserved for (explicit list):
1. Active progress step indicator circle (current step number)
2. "Seuraava" (Next) primary CTA button — filled black, white text
3. "Lähetä hyväksyttäväksi" final submit CTA — filled black, white text
4. "Auki" toggle when in ON state — `bg-[#111111]` thumb / track
5. Drop zone border when file is being dragged over (`border-[#111111]`)

Completed progress steps: checkmark icon in `text-[#111111]` on white circle with `border-[rgba(0,0,0,0.12)]` — NOT filled black (accent reserved for current step only).

Muted text: `text-[rgba(17,17,17,0.45)]` — helper text, addresses, optional labels, future progress steps.
Disabled text: `text-[rgba(17,17,17,0.35)]` — "Lisätään pian" pattern; empty pricing row placeholders.
Border default: `border-[rgba(0,0,0,0.07)]` — card separators.
Border interactive: `border-[rgba(0,0,0,0.12)]` — input fields, outlined secondary buttons.
Border interactive focus: `border-[rgba(0,0,0,0.25)]` — focused input fields.

Source: CLAUDE.md Color System; pattern confirmed in ClaimSearchForm.tsx and rekisteroidy/page.tsx.

## Visual Anatomy

### Progress Bar (top of every step)

```
[1 ✓] ── [2 ✓] ── [3 •] ── [4 ○] ── [5 ○] ── [6 ○]
  Paikka  Mediat  Hinnasto  Aukiol.  Yhteyst.  Esikats.
```

- Container: `glass rounded-2xl px-6 py-4 mb-6` — glass surface, not white flat.
- Step circle: 32px × 32px, `rounded-full`.
  - Completed (past): white fill, `border border-[rgba(0,0,0,0.12)]`, checkmark icon `text-[#111111]`.
  - Current (active): `bg-[#111111] text-white` — accent fill.
  - Future (locked): white fill, `border border-[rgba(0,0,0,0.07)]`, number `text-[rgba(17,17,17,0.35)]`.
- Connector line between circles: `h-px bg-[rgba(0,0,0,0.07)] flex-1`.
- Step label below circle: `text-[10px] font-bold uppercase tracking-widest` in matching muted/active color.
- Completed past steps: clickable (`cursor-pointer`) — navigates to that step directly. Future steps: `pointer-events-none`.

### Wizard Step Card

```
.glass rounded-2xl p-6 w-full max-w-xl mx-auto
└── flex flex-col gap-6
    ├── <h2 class="text-xl font-bold text-[#111111]">{step title}</h2>
    ├── {step content area — varies per step}
    └── <footer class="flex justify-between items-center pt-4 border-t border-[rgba(0,0,0,0.07)]">
            <button type="button">← Edellinen</button>   {not shown on step 1}
            <button type="submit">Seuraava →</button>     {or "Lähetä hyväksyttäväksi" on step 6}
        </footer>
```

Page wrapper: `min-h-screen bg-white flex flex-col items-center px-4 py-12`
Max width of wizard: `max-w-xl` (576px) — fits form and preview cards without excess whitespace.

### Step 2 — Upload Drop Zones

Two zones stacked vertically with `gap-6`:

**Logo zone:**
```
<div class="border-2 border-dashed border-[rgba(0,0,0,0.12)] rounded-xl p-6 flex flex-col items-center gap-3 min-h-[96px]
             hover:border-[rgba(0,0,0,0.25)] [transition:border-color_150ms_var(--ease-out)]
             [drag-over: border-[#111111] bg-[rgba(17,17,17,0.03)]]">
  {if no file: upload icon + "Logo (neliö, max 2 MB)" label}
  {if file selected: 64×64 rounded-lg img preview}
</div>
```

**Images zone:**
```
<div class="border-2 border-dashed border-[rgba(0,0,0,0.12)] rounded-xl p-4 min-h-[96px]
             hover:border-[rgba(0,0,0,0.25)] [transition:border-color_150ms_var(--ease-out)]
             [drag-over: border-[#111111] bg-[rgba(17,17,17,0.03)]]">
  {if no files: upload icon + "Kuvat 1–5 (max 5 MB / kuva)" label}
  {if files: horizontal thumbnail row, 64×64 each, gap-2, overflow-x-auto}
  {thumbnail remove: absolute top-1 right-1 × button 16×16}
</div>
```

Upload progress bar (shown during upload only, after "Seuraava" clicked):
- `w-full h-1 bg-[rgba(17,17,17,0.07)] rounded-full overflow-hidden`
- `inner: h-full bg-[#111111] rounded-full transition-[width] duration-300 ease-out`
- Appears below both drop zones, single bar tracking overall upload completion (0–100%).

### Step 3 — Hinnasto

Fixed category rows first, then dynamic rows:

```
<table class="w-full">
  <thead>
    <tr class="text-[10px] font-bold uppercase tracking-widest text-[rgba(17,17,17,0.45)]">
      <th class="text-left pb-2">Kategoria</th>
      <th class="text-left pb-2 w-28">Hinta (€)</th>
      <th class="text-left pb-2">Lisätieto (vapaaehtoinen)</th>
    </tr>
  </thead>
  <tbody class="divide-y divide-[rgba(0,0,0,0.07)]">
    {fixed rows: Kertakäynti / Kuukausijäsenyys / 10-kerran kortti / Vuosijäsenyys}
    {dynamic rows added by "+ Lisää hintarivi"}
  </tbody>
</table>
```

Row structure:
- Category label column: `text-sm text-[#111111] py-3 pr-4`; dynamic rows: text input `border-b border-[rgba(0,0,0,0.12)] text-sm outline-none w-full`.
- Price input: `border border-[rgba(0,0,0,0.12)] focus:border-[rgba(0,0,0,0.25)] rounded-lg h-9 px-2 text-sm w-28 tabular-nums`.
- Notes input: same style as price input but `w-full`.
- Dynamic row delete: `text-[rgba(17,17,17,0.35)] hover:text-red-600` × button at row end.

"+ Lisää hintarivi" button:
- `text-sm text-[#111111] font-bold underline-offset-2 hover:underline w-fit mt-2`

Validation: if zero rows have a price value, "Seuraava" stays disabled (`disabled:opacity-60 disabled:pointer-events-none`).

### Step 4 — Aukioloajat

7 rows (Ma / Ti / Ke / To / Pe / La / Su), each:

```
<div class="flex items-center gap-3 py-3 border-b border-[rgba(0,0,0,0.07)]">
  <span class="text-sm font-bold text-[#111111] w-8">{day}</span>
  <button role="switch" aria-checked={isOpen}
    class="w-10 h-6 rounded-full [transition:background-color_150ms_var(--ease-out)]

    <span class="w-5 h-5 rounded-full bg-white translate-x-[18px] (on) / translate-x-0.5 (off) transition-transform" />
  </button>
  {if isOpen:}
  <input type="time" class="border border-[rgba(0,0,0,0.12)] ... h-9 px-2 text-sm w-24" />
  <span class="text-sm text-[rgba(17,17,17,0.45)]">–</span>
  <input type="time" class="border border-[rgba(0,0,0,0.12)] ... h-9 px-2 text-sm w-24" />
  {if !isOpen:}
  <span class="text-sm text-[rgba(17,17,17,0.35)]">Suljettu</span>
```

## Animation Contract

All animations follow Emil Kowalski principles from CLAUDE.md.

| Element | Animation | Values |
|---------|-----------|--------|
| Step card enter/exit | `AnimatePresence mode="wait"`, opacity crossfade | `duration: 0.2, ease: "easeOut"` |
| Error message appear | `AnimatePresence`, opacity fade | `duration: 0.15` |
| Upload progress bar fill | Tailwind `transition-[width] duration-300 ease-out` | CSS only, no Framer Motion |
| "Seuraava" button tap | `whileTap={{ scale: 0.95 }}` | Only tap, no hover scale |
| Drop zone drag-over | CSS transition on border-color and background | `[transition:border-color_150ms_var(--ease-out)]` |
| Progress step transition | Re-render with key change triggers crossfade | `duration: 0.2` |
| Upload thumbnail row | New thumbnails fade in with `initial={{ opacity: 0 }} animate={{ opacity: 1 }}` | `duration: 0.15` |

No spring physics. No layout animations. No y-movement on view transitions.

Source: CLAUDE.md Animation Principles section.

## Form Validation Contract

| Step | Required to proceed | Error trigger |
|------|---------------------|---------------|
| Step 1 (Paikka) | Place already linked via Phase 33; name/address pre-filled — no extra validation. | If paikka_id missing: show `errorGeneric`. |

## Accessibility Contract

- Progress bar: `role="navigation"` on the progress container; `aria-current="step"` on active step circle.
- Opening hours toggles: `role="switch"` with `aria-checked={isOpen}` and `aria-label={t('hoursToggleLabel')}`.
- Upload drop zones: `role="button"` + `tabIndex={0}` + `onKeyDown` for Enter/Space activation; `aria-label` describing the zone.
- Error messages: `role="alert"` + `aria-live="polite"`.
- File inputs: visually hidden `<input type="file">` behind the drop zone div (accessible fallback for keyboard users).
- Time inputs: `<label htmlFor>` pairing for each time field, screen-reader-only label text where visual label is shared (e.g., "Aloitusaika", "Lopetusaika").
- Description textarea: `aria-describedby` pointing to the character counter element.
