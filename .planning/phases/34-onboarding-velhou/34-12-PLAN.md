    Two changes in this file:

    A) saveAndAdvance — merge saved data into local draft state.
    Current implementation (lines 114–116):
      function saveAndAdvance(stepNum: number) {
        goToStep(stepNum + 1)
      }
    Each step component (StepHinnasto, StepAukioloajat, StepYhteystiedot) calls
    onNext() after a successful API save. The parent saveAndAdvance only navigates.
    Because draft state is never updated, going back to step 4 passes the
    mount-time draft.aukioloajat (null) as initialDraftAukioloajat.

    Replace saveAndAdvance with a version that re-fetches the draft from Supabase
    immediately after the API returns (re-fetch is safer than partial merges because
    each step saves its own JSONB field and we cannot pass the value up without
    refactoring all step components):

      async function saveAndAdvance(stepNum: number) {
        // Re-fetch the latest draft so that back-navigation passes fresh initialProps
        // to each step component. This also updates draftAsPaikka on step 6.
        try {
          const supabase = createBrowserSupabase()
          const { data: { user } } = await supabase.auth.getUser()
          if (user) {
            const { data: freshDraft } = await supabase
              .from('onboarding_draft')
              .select('*')
              .eq('business_account_id', user.id)
              .maybeSingle()
            if (freshDraft) setDraft(freshDraft as OnboardingDraft)
          }
        } catch {
          // Non-critical: if re-fetch fails, proceed anyway — user navigates forward
        }
        goToStep(stepNum + 1)
      }

    This makes saveAndAdvance async. Callers pass it as onNext={() => saveAndAdvance(N)}
    which is already a void callback — the async signature is transparent to callers.

    B) Step 6 draft refresh on re-entry.
    The current useEffect has empty deps [] so draft is only loaded once at mount.
    Add a second small useEffect that re-fetches the draft when the user navigates
    to step 6 (step === 6). Place it after the existing loadDraft useEffect:

      useEffect(() => {
        if (step !== 6) return
        async function refreshDraftForPreview() {
          try {
            const supabase = createBrowserSupabase()
            const { data: { user } } = await supabase.auth.getUser()
            if (!user) return
            const { data: freshDraft } = await supabase
              .from('onboarding_draft')
              .select('*')
              .eq('business_account_id', user.id)
              .maybeSingle()
            if (freshDraft) setDraft(freshDraft as OnboardingDraft)
          } catch { /* ignore */ }
        }
        refreshDraftForPreview()
      }, [step])

    This ensures StepEsikatselu always receives an up-to-date draft regardless of
    whether saveAndAdvance re-fetch succeeded.
