## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (gap-1) | Star button gap in StarPicker row |
| sm | 8px (gap-2) | Star average inline gap (stars / number / count) |
| md | 16px (gap-4) | Row icon + label gap in page.tsx Row component |
| lg | 24px (p-6) | ReviewSection card padding default |
| xl | 32px (p-8) | ReviewSection card padding sm: breakpoint |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- ReviewForm internal gap: `gap-3` (12px) — matches ProfiiliClient.tsx card interior spacing
- ReviewCard internal gap: `gap-2` (8px) — compact review item
- Crowd pill gap: `gap-2` (8px) — three pills side-by-side
- Touch target for StarPicker buttons: minimum 44px tall via `py-2 text-2xl leading-none` — accessible tap target on mobile

## Typography

All sizes drawn from the 4-size / 2-weight system in CLAUDE.md. No new sizes or weights introduced.

| Role | Size | Weight | Line Height | Tailwind Class | Usage in Phase 15 |
|------|------|--------|-------------|----------------|-------------------|
| Micro / badge | 10px | 700 (bold) | n/a (single line) | `text-[10px] font-bold uppercase tracking-widest` | Section label "ARVOSTELUT", form field labels ("TÄHTIARVOSANA", "KOMMENTTI", etc.) |
| Body / UI label | 14px (text-sm) | 400 (normal) or 700 (bold) | 1.5 | `text-sm` / `text-sm font-bold` | Review text body (400), author name (bold), count in avg display (400 muted), button labels (bold), textarea placeholder |
| Subheading | 20px (text-xl) | 700 (bold) | 1.2 | `text-xl font-bold` | Not used in this phase (no new subheadings) |
| Display heading | 30–36px (text-3xl sm:text-4xl) | 700 (bold) | 1.2 (leading-tight) | `font-serif text-3xl sm:text-4xl font-bold leading-tight tracking-tight` | Venue name in hero — existing, not modified |

> Semibold (600) is banned. Use bold (700) for emphasis, normal (400) for body. No exceptions.

> **Icon-sizing note:** `text-2xl` appears on StarPicker star buttons (`className="text-2xl leading-none"`). This is an icon-sizing utility applied to a Unicode glyph character — it is not a typographic scale entry and does not constitute a 5th font-size in the typography system.

This is the only amber in the reviews system. The existing sponsored badge amber (`bg-amber-100 text-amber-700`) is unrelated and already established.

## Interaction Contracts

### StarPicker Interactions

| Trigger | Response | Duration |
|---------|----------|----------|
| Mouse enter star N | Stars 1–N turn amber-400 (hover preview) | Instant (no transition on color) |
| Mouse leave container | Revert to selected value | Instant |
| Click star N | `onChange(n)` — selection locked | — |
| Tap star N (mobile) | Same as click | — |
| `whileTap` | `scale: 0.95`, duration 0.12s, ease easeOut | 120ms |

### CrowdRatingPills Interactions

| Trigger | Response |
|---------|----------|
| Tap inactive pill | Select it (active style) |
| Tap active pill | Deselect (returns to null) |
| `whileTap` | `scale: 0.95` |

### "Näytä kaikki" Button

Shown only when `initialReviews.length > 5` and `showAll === false`.

Label: `"Näytä kaikki (N arvostelua)"` where N = total count.

Style: `text-sm font-bold text-[#111111] underline underline-offset-2 self-start` — no background, no border. Plain text link appearance.

On click: `setShowAll(true)`. Button disappears (not replaced with "Näytä vähemmän" — collapse is out of scope).

### Form Submission

Submit button disabled when `rating === 0` (no star selected). Disabled state: `opacity-50 cursor-not-allowed pointer-events-none`.

On submit:
1. Button shows loading: label changes to "Tallennetaan…", `disabled`.
2. On success: `router.refresh()` to revalidate server data (fresh avgRating from page.tsx). Confirmation: `<p className="text-sm text-green-700">Arvostelu tallennettu</p>` (auto-hides after 2500ms, same as ProfiiliClient).
3. On error: `<p className="text-sm text-red-600">Tallennus epäonnistui. Yritä uudelleen.</p>` (persists until next submit attempt).

### Animation Principles

| Element | Animation | Spec |
|---------|-----------|------|
| StarPicker button | `whileTap={{ scale: 0.95 }}` | duration 0.12s, ease easeOut |
| CrowdRatingPills | `whileTap={{ scale: 0.95 }}` | default framer duration |
| AnonymousToggle | `whileTap={{ scale: 0.95 }}` | default framer duration |
| Submit button | No scale (layout element — scale conflicts with text) | `[transition:background-color_150ms_var(--ease-out)]` only |
| ReviewSection mount | No entrance animation — section is below fold, stagger not needed | Static render |
| ReviewCard | No animation — list items are server-fetched, not staggered | Static render |

> No spring physics. No layout animations. No y-movement.
