<objective>
Add the `business_accounts.display_name` column (D-05) and close the confirmed invite-link signup wiring gap (D-15) so that display_name has a reachable code path for genuinely new invite-link employees. This plan fixes that round-trip and collects the name in that same form.

Purpose: Provide the identity data (real names) the ACCESS-04 dashboard popup displays, and repair the invite onboarding path it depends on.
Output: New migration (applied), extended register handler, fixed signup page, extended tests, new i18n keys.
</objective>
