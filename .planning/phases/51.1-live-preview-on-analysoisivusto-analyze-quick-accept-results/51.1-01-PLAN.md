<objective>
Thread a full `PaikkaBase` (`nimi`, `laji`, `osoite`, `kaupunki`, `latitude`, `longitude`) from the pre-wizard place-resolution step into `AnalysoiSivusto`, so the live preview added in Plan 02 has the place data `LivePreviewProvider` requires.

Purpose: `LivePreviewProvider` requires a `paikkaInfo: PaikkaBase | null` prop (see `lib/livePreview/LivePreviewContext.tsx` lines 120-126). `AnalysoiSivusto` currently receives only `paikkaId` — it has no place data to feed the provider. `StepPaikkaPrePhase` already fetches a partial place row (`nimi, osoite, kaupunki`) but never forwards it. This plan extends that fetch to the full `PaikkaBase` shape and plumbs it through `OnboardingWizardPage` state into `PrePhase` → `AnalysoiSivusto` (D-06). This is the blocking prerequisite for Plan 02.

Output: `app/business/onboarding/page.tsx` modified — extended Supabase select, new page-level `paikkaInfo` state, new prop threaded into `AnalysoiSivusto`.
</objective>
