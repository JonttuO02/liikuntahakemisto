<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LanguageToggle → changeLocaleAction | Client component calls server action; locale value is constrained to 'fi' \| 'en' by TypeScript |
| NEXT_LOCALE cookie → router.refresh() | Cookie write must complete (await) before refresh to avoid stale-locale re-render |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-06 | Tampering | LanguageToggle — toggle call race condition | mitigate | `startTransition(async () => { await changeLocaleAction(next); router.refresh() })` ensures cookie write completes before refresh; RESEARCH.md Pitfall 2 documents this |
| T-30-07 | Information Disclosure | ProfiiliClient — user email displayed | accept | Email is shown to the authenticated user only; no new disclosure introduced by this plan |
| T-30-SC | Tampering | No new npm installs in this plan | accept | — |
