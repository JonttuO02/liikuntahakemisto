    - .planning/phases/11-pwa/11-CONTEXT.md D-16 — indigo #4F46E5, two sizes 192 and 512, script at scripts/generate-pwa-icons.mjs
  </read_first>
  <action>
    Create the scripts/ directory if it does not exist, then create scripts/generate-pwa-icons.mjs as an ES module.

    The script must:
    - Import PImage from "pureimage" and fs and path from Node built-ins using import syntax (ESM — .mjs extension)
    - Resolve publicDir relative to import.meta.url using fileURLToPath + path.dirname (not __dirname, which does not exist in ESM)
    - Define an async generateIcon(size) function that:
      - Calls PImage.make(size, size) to create the canvas
      - Gets context via img.getContext('2d')
      - Sets ctx.fillStyle = '#4F46E5' (indigo-600, matches theme_color per D-17)
      - Calls ctx.fillRect(0, 0, size, size)
      - Calls PImage.encodePNGToStream(img, fs.createWriteStream(outputPath)) and awaits it
      - Logs the output path to console
    - Call generateIcon(192) and generateIcon(512) at the top level with await (top-level await is valid in .mjs)

    After writing the script, run it: `node scripts/generate-pwa-icons.mjs`

    The script should complete without error and produce public/icon-192x192.png and public/icon-512x512.png.
  </action>
