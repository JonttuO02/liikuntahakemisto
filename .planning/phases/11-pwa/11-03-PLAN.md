<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → /manifest.webmanifest | Browser fetches manifest to determine installability |
| Browser → /offline | SW intercepts document navigations and serves /offline from precache when device is offline |
| Installed PWA → app | Installed app launches at start_url /?nakyma=lista; SW intercepts and may serve from cache |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-08 | Information Disclosure | /offline page content | accept | /offline page contains no user data or auth state; it is a static server component precached at install |
| T-11-09 | Tampering | manifest.ts start_url points to listing page | accept | start_url = "/?nakyma=lista" is publicly accessible; no auth gate; no PII exposed via manifest |
| T-11-10 | Elevation of Privilege | appleWebApp: capable: true | accept | This metadata enables iOS fullscreen mode; no privilege change, no new attack surface |
| T-11-11 | Information Disclosure | themeColor in viewport export vs metadata | mitigate | Using viewport export (not deprecated metadata.themeColor) prevents build warnings and ensures tag renders correctly in production |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No new packages in this plan; all packages installed in Plan 01 |
</threat_model>
