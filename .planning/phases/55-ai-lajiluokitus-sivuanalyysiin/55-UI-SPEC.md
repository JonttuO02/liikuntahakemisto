# Phase 55 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase adds **no new visual language** — CONTEXT.md's `<specifics>` is explicit: the suggestion card and Vaihda picker must look like a natural extension of `AnalysoiSivusto.tsx`'s existing logo-candidate/color-swatch pickers. Every value below is therefore pre-populated from the project's existing design system (CLAUDE.md + direct read of `AnalysoiSivusto.tsx`), not invented for this phase. shadcn is initialized but this screen does not currently consume shadcn `ui/` primitives directly — it uses hand-rolled sub-components (`LabelCaps`, `PrimaryButton`, `MutedButton`, `Spinner`) that already encode the project's button/label vocabulary. New UI in this phase reuses those sub-components verbatim; no new shadcn component installs are needed.

## Spacing Scale

Declared values (must be multiples of 4, matching `AnalysoiSivusto.tsx`'s existing Tailwind spacing):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`) | Icon-to-label gaps, tight stacked text (e.g. swatch label + hex code) |
| sm | 8px (`gap-2`) | Compact element spacing — label row, button internal gap, picker chip gap |
| md | 16px (`p-2` button padding / `gap-2`–`gap-3` row spacing) | Default control spacing — matches existing logo-candidate/color-armed-slot button padding |
| lg | 24px (`gap-6`, `p-6`) | Section-to-section spacing inside `editContent` (matches outer `.glass rounded-2xl p-6 flex flex-col gap-6` wrapper and existing block-to-block gaps) |
| — | 40px (`h-10`) | Button/input height — `PrimaryButton`/`MutedButton`/hex input all use `h-10` |

Exceptions: none. The suggestion card and Vaihda picker reuse the exact spacing tokens already present in the Logo/Brändivärit/Galleria blocks (`flex flex-col gap-2` per block, `gap-6` between blocks).

## Copywriting Contract

All copy in Finnish, matching the existing screen's tone (direct, second-person imperative, no exclamation marks). Mirrors the existing "Logoa ei löytynyt automaattisesti — voit lisätä sen myöhemmin..." pattern for the empty/fallback case.

| Element | Copy |
|---------|------|
| Suggestion card label | `LabelCaps`: **"Laji"** (matches "Logo"/"Brändivärit"/"Galleria" — singular, capitalized section name, no "ehdotettu" prefix in the label itself; the word "Ehdotettu" lives in the body line per D-01) |
| Suggestion card body (confirmed/suggested state) | **"Ehdotettu laji: {label}"** — `{label}` is `lajiKonfig[suggested_laji].label` (e.g. "Padel"), rendered `text-sm font-bold text-[#111111]` to visually distinguish it from the muted helper copy used elsewhere (this bold treatment IS the "erottuva ehdotus-elementti" — no badge/pill shape needed, weight + the two-button row is enough to read as distinct from logo/color pickers) |
| Vahvista button | **"Vahvista"** (PrimaryButton, accent `#111111`) |
| Vaihda button/link | **"Vaihda"** (MutedButton style — muted gray, hover to `#111111`, same visual weight as "Analysoi uudelleen") |
| Unconfirmed/fallback state heading | Same `LabelCaps`: **"Laji"** |
| Unconfirmed/fallback state body | **"Lajia ei tunnistettu automaattisesti — valitse lajikategoria"** (mirrors "Logoa ei löytynyt automaattisesti — voit lisätä sen myöhemmin velhon Mediat-vaiheessa" structure: problem statement + immediate next step). No Vahvista button rendered in this state — only a single **"Valitse laji"** button (PrimaryButton, since this is the path forward, not a secondary action) that opens the same Vaihda picker. |
| Vaihda picker heading | **"Valitse lajikategoria"** |
| Vaihda picker taxonomy option labels | `lajiKonfig[key].label` for all 9 keys, rendered as a button grid identical in shape to the logo-candidate grid (`flex flex-row flex-wrap gap-2`, `border rounded-lg p-2`, selected state `border-[#111111] ring-2 ring-[#111111]`) |
| Vaihda picker free-text input | Placeholder: **"Muu laji…"**; label: `LabelCaps` **"Muu"** above the input, consistent with the existing "Oma värikoodi" custom-hex input pattern (`border-[rgba(0,0,0,0.12)] rounded-lg h-10 px-3 text-sm`) |
| Vaihda picker free-text submit | **"Käytä"** (MutedButton, same as the existing hex-input "Käytä" button) |
| Vaihda picker free-text validation error | **"Anna lajin nimi (enintään 100 merkkiä)"** — `text-sm text-red-600 role="alert"`, same shape as `customHexError`/`saveError` |
| Vaihda picker close/cancel | **"Peruuta"** (MutedButton) — closes the picker without changing the current confirmed/unconfirmed state |
| Skip-path manual picker intro copy | **"Valitse paikan lajikategoria ennen jatkamista"** — placed wherever the planner inserts D-06's picker (no AI badge, reuses the same picker body, no "Ehdotettu"/Vahvista framing since there is no AI suggestion to confirm) |
| Re-analysis reset (no new copy needed) | Suggestion card silently returns to its initial loading/empty state when `onReanalyze` fires, identical to how the logo/color blocks reset — no toast or message required |
| Destructive actions | None in this phase. Changing the laji selection (Vaihda) is reversible and unconfirmed values never write to the database (D-04) — no confirmation dialog needed for any action here. |

## Interaction States (component contract)

This section captures the four required render states for the suggestion card, since D-01/D-03 specify they must look visually distinct from each other, not just from the logo/color pickers.

| State | Trigger | Visual treatment | Available actions |
|-------|---------|-------------------|--------------------|
| **Suggested (unconfirmed-but-valid)** | `brandingResult.suggested_laji` is a valid taxonomy key AND user has not yet clicked Vahvista/Vaihda | `LabelCaps` "Laji" + body "Ehdotettu laji: {label}" in `text-sm font-bold text-[#111111]` | Vahvista (PrimaryButton) + Vaihda (MutedButton), side by side `flex flex-row gap-2` — same row shape as the footer's two-button group |
| **Confirmed (post-Vahvista or post-Vaihda-pick)** | User clicked Vahvista, or picked a category in Vaihda | Body text becomes **"Laji: {label}"** (drops "Ehdotettu" prefix — this text change IS the confirmation feedback signal), still `text-sm font-bold text-[#111111]` | Only Vaihda remains visible (MutedButton) — lets the user change their mind without a re-confirm step; no Vahvista shown since there's nothing left to confirm |
| **Unconfirmed (D-03 fallback)** | `suggested_laji` is `null`/invalid OR Claude omitted the field | Body text: "Lajia ei tunnistettu automaattisesti — valitse lajikategoria" in `text-sm text-[rgba(17,17,17,0.45)]` (muted, NOT bold — this is the visual differentiator from the confirmed/suggested states) | Only **"Valitse laji"** (PrimaryButton) — opens Vaihda picker; no Vahvista possible since there is no suggestion to confirm |
| **Picker open (Vaihda)** | User clicks Vaihda or "Valitse laji" | Replaces the card body in place (inline expansion, not a modal — consistent with this screen having no existing modal pattern; armedSlot-style inline swap) with: heading, 9-key button grid, free-text input + Käytä, Peruuta | Selecting a taxonomy option or submitting free text closes the picker and returns to the Confirmed state; Peruuta closes without change |

**Placement:** insert the suggestion card block between the Galleria block (ends ~line 407) and the Hinnat block (starts ~line 409), per RESEARCH.md's recommended slot — keeps all AI-extracted-and-confirmable fields (Logo, Brändivärit, Galleria, Laji) grouped together before the read-only Hinnat/Aukioloajat display blocks.

**Skip-path picker (D-06):** same 4th row ("Picker open") body only — no Suggested/Confirmed/Unconfirmed states apply since there is no AI suggestion. Render directly as an open picker (taxonomy grid + free text), introduced by the "Valitse paikan lajikategoria ennen jatkamista" copy above, with no AI badge or "Ehdotettu" framing anywhere.
