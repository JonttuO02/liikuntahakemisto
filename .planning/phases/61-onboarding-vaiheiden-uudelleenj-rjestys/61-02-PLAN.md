<objective>
Create the two new pre-wizard step components — `StepNimiJaURL` (name + optional website) and `StepSijainti` (location picker) — and simplify `ClaimSearchForm` so location is no longer collected before onboarding begins. Together these move location collection out of the create form and into a dedicated second onboarding step, and introduce the website-URL collection point.

Purpose: These are the building blocks the page-level state machine (Plan 04) wires together. They are new/standalone files plus one isolated form modification, so they parallelize cleanly against the wizard-finalization plan (Plan 03).
Output: Two new client components and a simplified ClaimSearchForm.
</objective>
