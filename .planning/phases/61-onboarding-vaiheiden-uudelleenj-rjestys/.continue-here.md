- [ ] CONSTRAINT: JSONB clobber — save-step UPSERT replaces the entire `yhteystiedot` column, not merging. Saving `{puhelin,email,kuvaus}` at step 4 overwrites the `{website:url}` saved at step 1. Fix must include `website` in the step-4 payload or switch to merge semantics.
- [ ] CONSTRAINT: Fast-forward websiteUrl gap — `handleNimiUrlNext(null)` sets `websiteUrl=null` in state; sijainti `onNext` uses state (not draft) to route to analyze vs. handleSkip. Resuming users who had a website are silently misrouted to laji-skip. Fix must re-hydrate `websiteUrl` from draft OR skip both nimi-url and sijainti for users where `paikka.latitude !== null`.
- [ ] CONSTRAINT: Back-loop after sijainti save — pressing Back from sijainti sets `pagePhase='nimi-url'`, remounting `StepNimiJaURLPrePhase` whose `useEffect` re-fetches the paikka and fast-forwards again if `paikka.latitude !== null`. Fix must prevent the fast-forward from firing when the user explicitly navigated back.

**Do not proceed to UAT until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| JSONB column replace semantics | save-step UPSERT replaces the entire JSONB column; writing a partial value at one step silently clobbers values written by an earlier step | blocking | Always include all relevant fields in each save-step write, OR read the current draft value and merge before writing |
| Dead guard state | `aiTriggered` was set but never checked before firing fetches — the deduplication guard never ran | advisory | Before adding guard state, wire the check immediately: `if (guard) return` at the top of the guarded block |
| Unawaited async callback | `onNext()` typed as `() => void` but receiving `async handleYhteystiedotSubmit` — `finally` fires before submit resolves | blocking | Type `onNext` as `() => Promise<void>` and `await onNext()` when the callback is async and the caller owns loading state |
