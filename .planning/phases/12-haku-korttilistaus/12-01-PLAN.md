# Plan 12-01: Redirect & route cleanup

**Phase:** 12 — Haku & korttilistaus etusivulle
**Goal:** Remove the `/?nakyma=lista` route from the app — add a permanent redirect and strip the dead render branch

---

## Context

`app/page.tsx` currently has an `if (searchParams.nakyma === 'lista')` branch that renders `LiikuntapaikatLista`. After this plan, that branch is gone. The redirect ensures any bookmark or link using `?nakyma=lista` lands on `/`.

`next.config.mjs` currently precaches `/?nakyma=lista` for the service worker — that entry must be removed alongside the redirect addition.

---

## Tasks

### T1 — Add permanent redirect in `next.config.mjs`

File: `next.config.mjs`

1. Add an `async redirects()` function inside the object passed to `withSerwist(...)`:

```js
async redirects() {
  return [
    {
      source: '/',
      has: [{ type: 'query', key: 'nakyma', value: 'lista' }],
      destination: '/',
      permanent: true,
    },
  ]
},
```

2. Remove `{ url: "/?nakyma=lista", revision }` from the `additionalPrecacheEntries` array. The array will have only `{ url: "/offline", revision }` remaining.

### T2 — Clean up `app/page.tsx`

File: `app/page.tsx`

1. Remove the `LiikuntapaikatLista` import line.
2. Remove the `searchParams` prop from the `Home` function signature and its TypeScript type annotation (`{ searchParams: { nakyma?: string } }`). The function becomes `export default async function Home()`.
3. Remove the `if (searchParams.nakyma === 'lista')` block and its return statement entirely.
4. Remove the stale comment `// nakyma=kartta also renders Etusivu...` that referenced the old routing logic.

---

## Verification

- `app/page.tsx` no longer imports or renders `LiikuntapaikatLista`
- `next.config.mjs` has `redirects()` returning the `/?nakyma=lista → /` entry
- `next.config.mjs` `additionalPrecacheEntries` has only the `/offline` entry
- TypeScript compiles without errors (`npx tsc --noEmit`)
