## Component Inventory

### 1. `ContrastSafeLogo` (new primitive — D-03)

- **Purpose:** Render a logo thumbnail against a guaranteed non-white, non-transparent backdrop so white/transparent-background logos remain visible.
- **Suggested location:** `app/components/ContrastSafeLogo.tsx` (co-locating in `app/business/onboarding/` is also acceptable per CONTEXT.md's discretion note — prefer `app/components/` since other shared presentational primitives like `CalloutCard`, `DiagonaalKortti` live there).
- **Props:** `{ src: string; alt?: string; className?: string }` — single-purpose, presentational only. No dependency on `BrandingResult` or any branding-aware type; takes a plain URL string. Do not give it knowledge of `logo_candidates[].type` or selection state — that stays in `AnalysoiSivusto.tsx`.
- **Markup contract:**
  ```tsx
  <div className="w-full h-12 rounded-lg bg-[rgba(0,0,0,0.06)] flex items-center justify-center overflow-hidden">
    <img src={src} alt={alt ?? ''} className="h-full w-auto object-contain" />
  </div>
  ```
  - Backdrop: `rgba(0,0,0,0.06)` (D-04, matches `DiagonaalKortti`'s precedent exactly — do not invent a new tint or a checkerboard/transparency-aware pattern).
  - Corner radius: `rounded-lg` to match the existing picker button's `rounded-lg` (the button wrapper in `AnalysoiSivusto.tsx` already uses `rounded-lg` — the new primitive's radius should visually nest, not clash).
  - Height: `h-12` (48px) — preserves the exact footprint of the `<img>` it replaces (`className="h-12 w-auto object-contain rounded"` at line 611-615). Width fills the button's content area (`w-full`) so the backdrop box reads as a deliberate frame, not a tight wrapper around the image only.
  - No animation — this is a static, non-interactive visual fix. The parent `<button>` already owns hover/selected-state styling (`border`, `ring-2`); `ContrastSafeLogo` does not add its own hover or transition behavior.

- **Call site (only one this phase):** `app/business/onboarding/AnalysoiSivusto.tsx` ~line 611, inside the logo-candidate picker's `.map()`, replacing the bare `<img src={candidate.url} ... />`:
  ```tsx
  <ContrastSafeLogo src={candidate.url} />
  ```
- **Explicitly NOT touched:** `DiagonaalKortti.tsx` lines 94-107 (own `rgba(0,0,0,0.06)` box, kept as-is, NOT refactored to use the new primitive), `PaikkaSheet.tsx` lines 158-170 (own `rgba(255,255,255,0.15)` box, kept as-is).

### 2. Step 6 `CalloutCard` swap (D-01, D-02)

This matches `CalloutCard`'s actual prop surface (it has none for interaction beyond its own internal name/sport toggle animation, which is fine to keep running here exactly as it does on the live map).
