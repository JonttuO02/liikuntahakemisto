The button is 40px tall (w-10 h-10), so it occupies:
  top edge: calc(max(12px, env(safe-area-inset-top)) + 48px)
  bottom edge: calc(max(12px, env(safe-area-inset-top)) + 88px)
At minimum (safe-area-inset-top = 0): top = 60px, bottom = 100px from viewport top.
The sheet opens from bottom, height = contentH. For the button to stay clear, the sheet top
edge must be ≥ 100px from viewport top, meaning: fullH - contentH ≥ 100px.
So contentH ≤ fullH - 100. With typical fullH ~844px (iPhone 14): 0.82 × 844 = 692px;
fullH - 692 = 152px. The button bottom is at 100px — so 0.82 already clears it nominally.
However, add 8px safety margin to ensure the sheet does not visually overlap the button on
smaller screens: target contentH = fullH - 108, capped to avoid making sheet too small.
Use: `const contentH = Math.round(Math.min(fullH * 0.82, fullH - 108))`
